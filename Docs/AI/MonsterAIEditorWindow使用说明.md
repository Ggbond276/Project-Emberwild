# 怪物 AI 配置工作台使用说明

## 打开方式

在 Unity 顶部菜单选择：

```text
Emberwild > 怪物 AI > 怪物配置工作台
```

窗口会读取项目根目录下的 `Data/Data` 七张配置表。

> 本工具直接修改 `Data/Data` 中的 JSON 产物，不会回写
> `Data/Tables/*.xlsx`。如果继续运行 `Excel2Json`，Excel 旧内容会覆盖
> 工作台中保存的修改。

## 基本流程

1. 在左侧按 `[TID] 名称` 选择怪物。
2. 在三个标签页中修改配置。
3. 点击顶部“校验数据合法性”。
4. 修正错误后点击“保存全部表并刷新资源”。

只有校验没有错误时才允许保存。警告不会阻止保存。

## 基础与躯体

- TID 创建后不可修改。
- `怪物名称`会同时写入 CharacterDefine 和 MonsterAI。
- `SubType`必须与 AttackDefine 的 `ComboGroup` 一致。
- `Prefab 资源路径`相对于 Resources 目录填写。
- HP、AD、DEF 决定角色出生时的战斗属性。
- 感知、移动和 Animator 根参数直接使用中文说明。

## 大脑决策树

- 行为规则越靠上，优先级越高。
- 可拖动规则改变顺序。
- 每条规则的条件必须全部满足。
- 空条件列表表示该规则始终成立。
- 条件类型使用下拉选择，只显示该条件真正需要的参数。
- 保存时会自动重排 `RuleIndex` 和 `ConditionIndex`。

常用条件参数：

| 条件 | 参数 |
|---|---|
| 有目标 | 无 |
| 血量低于 | 0 到 1 的血量比例 |
| 距离在区间内 | 最小距离、最大距离 |
| 技能冷却完成 | 技能、冷却秒数 |
| 技能槽可用 | 技能槽、冷却秒数 |
| 技能槽未使用 | 技能槽 |
| 攻击冷却完成 | 冷却秒数 |

## 技能与打击盒

- `AbilityId` 在同一只怪物中必须唯一。
- 技能槽与执行器均为受控下拉。
- `一次性动画语义` 和 `持续状态语义`从统一语义列表选择。
- 动画映射按 `TID + SemanticKey` 共享，同一语义只能映射一次。
- 攻击段通过 `SubType + ComboIndex` 关联。
- 圆形判定参数：半径。
- 矩形判定参数：宽度、长度。
- 扇形判定参数：半径、角度。

## 新增与删除

新增怪物会自动生成：

- CharacterDefine 与 MonsterAI 基础行。
- 受击能力。
- 死亡能力。
- 一条待机规则。
- 默认移动与死亡 Animator 参数。

仍需填写 Prefab 资源路径和需要的技能、动画、攻击配置。

删除怪物会删除该 TID 的能力、行为、条件和动画配置。共享的 AttackDefine 不会自动删除。

## 保存与运行

保存后会：

1. 自动重排 Ability、Animation、Behavior、Condition 的外层 Key。
2. 自动重排行为规则和条件索引。
3. 写回七张 `.txt` 文件。
4. 调用 `AssetDatabase.Refresh()`。
5. 尝试刷新 `MonsterAIDefinitionRepository` 缓存。

Play Mode 中保存会更新数据缓存，但场上已经生成的怪物仍保留旧运行时状态。需要重新出生或重新进入 Play Mode 才能完全应用。
