## 步骤 1：让 `CombatAttribute` 扣血后发事件（🔴 核心）

**为什么？** 现在 `TakeDamage` 只扣血 + 打日志，没人知道"谁挨打了"，所以怪物不会播受击、玩家不播 GetHit。这里把"扣血"变成"扣血 + 广播"。

**文件**：`Assets/Scripts/Combat/CombatAttribute.cs`

**整体替换**为下面内容（关键变化：① 加 `using Emberwild.Core.Events;` ② 加 `_entity` 识别阵营 ③ `TakeDamage` 扣血后按阵营发事件）：

```csharp
using Emberwild.Core.AppLog;
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.Combat
{
    /// <summary>
    /// 每个参与战斗的角色身上都会挂载。
    /// 阶段三起:扣血后按阵营发布受击/死亡事件,驱动下游反馈。
    /// </summary>
    [DisallowMultipleComponent]
    public class CombatAttribute : MonoBehaviour
    {
        [field: SerializeField] public float MaxHp { get; private set; }
        [field: SerializeField] public float CurrentHp { get; private set; }
        [field: SerializeField] public float CurrentAD { get; private set; }
        [field: SerializeField] public float CurrentDEF { get; private set; }

        public bool IsDead { get; private set; }

        // 用于识别阵营(玩家/怪物),扣血后发布对应事件
        private ICombatEntity _entity;

        private void Awake()
        {
            _entity = GetComponent<ICombatEntity>();
        }

        public void Initialize(float maxHp, float currentHp, float baseAD, float baseDEF)
        {
            MaxHp = maxHp;
            CurrentHp = currentHp;
            CurrentAD = baseAD;
            CurrentDEF = baseDEF;
            IsDead = currentHp <= 0;
        }

        public void TakeDamage(float damageAmount)
        {
            if (IsDead) return;

            CurrentHp = Mathf.Max(0, CurrentHp - damageAmount);
            AppLog.Info("Combat", $"{gameObject.name} 受到 {damageAmount:F1} 伤害, 剩余 HP: {CurrentHp:F1}");

            if (CurrentHp <= 0)
            {
                IsDead = true;
                PublishDiedEvent();
                AppLog.Info("Combat", $"{gameObject.name} 死亡");
            }
            else
            {
                PublishDamagedEvent(damageAmount);
            }
        }

        /// <summary>死亡:只发死亡事件,不再发受击事件(避免受击动画覆盖死亡动画)。</summary>
        private void PublishDiedEvent()
        {
            if (_entity == null) return;
            if (_entity.Faction == FactionType.Player)
                EventBus.Publish(new CharacterDiedEvent());
            else
                EventBus.Publish(new EnemyDiedEvent());
        }

        /// <summary>受击:发对应阵营的受击事件。</summary>
        private void PublishDamagedEvent(float damage)
        {
            if (_entity == null) return;
            if (_entity.Faction == FactionType.Player)
                EventBus.Publish(new CharacterDamagedEvent(damage, CurrentHp, Vector3.zero));
            else
                EventBus.Publish(new EnemyDamagedEvent(damage, CurrentHp, Vector3.zero));
        }
    }
}
```

**✅ 预期结果**：编译 0 报错。

**❓ 常见问题**：
- 报 "CharacterDiedEvent / EnemyDamagedEvent 找不到" → 确认文件顶部有 `using Emberwild.Core.Events;`。
- 报 "ICombatEntity 找不到" → `ICombatEntity` 在 `Emberwild.Combat` 命名空间，本文件也在该命名空间，无需额外 using。

## 步骤 3：新增 `HitState.cs`（受击硬直）

**为什么？** 被打时要"打断当前动作 + 播受击 + 硬直一小段时间"，结束后恢复追击。固定硬直时长从 `brain.HitStunDuration` 读，便于在 Inspector 调。

新建 `Assets/Scripts/AI/Enemy/State/HitState.cs`：

```csharp
using UnityEngine;

namespace Emberwild.AI.Enemy.State
{
    /// <summary>
    /// 受击硬直状态:打断一切 → 播 TakeDamage → 硬直结束回归 Chase/Idle。
    /// </summary>
    public class HitState : IEnemyState
    {
        private float _hitEndTime;

        public void OnEnter(EnemyBrain brain)
        {
            _hitEndTime = Time.time + brain.HitStunDuration;

            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);
            brain.Animator.PlayTakeDamage();
        }

        public void OnUpdate(EnemyBrain brain)
        {
            if (Time.time >= _hitEndTime)
            {
                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
            }
        }

        public void OnExit(EnemyBrain brain)
        {
            // 无需清理
        }
    }
}
```

**✅ 预期结果**：此时会报 `EnemyBrain` 没有 `HitStunDuration`——正常，步骤 5 加上即可。

## 步骤 4：新增 `DeadState.cs`（死亡终止态）

**为什么？** 死亡是最高优先级、不可打断的终止态：播 Die、停止移动、停止感知，尸体彻底静止。

新建 `Assets/Scripts/AI/Enemy/State/DeadState.cs`：

```csharp
namespace Emberwild.AI.Enemy.State
{
    /// <summary>
    /// 死亡状态:最高优先级、不可打断的终止态。
    /// 播 Die 动画,禁用移动与感知,尸体静止。
    /// </summary>
    public class DeadState : IEnemyState
    {
        public void OnEnter(EnemyBrain brain)
        {
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);
            brain.Animator.SetDead(true);

            // 尸体不再移动、不再感知
            brain.Agent.enabled = false;
            brain.Perception.enabled = false;
        }

        public void OnUpdate(EnemyBrain brain)
        {
            // 终止态,无出口
        }

        public void OnExit(EnemyBrain brain)
        {
            // 不会走到这里
        }
    }
}
```

**✅ 预期结果**：编译通过（`brain.Agent` / `brain.Perception` / `brain.Animator` 在 `EnemyBrain` 里都有公开属性）。

**⑤ 在类里新增订阅/回调方法**（放在 `Start` 方法之后）：

```csharp
        private void OnEnable()
        {
            EventBus.Subscribe<EnemyDamagedEvent>(OnDamaged);
            EventBus.Subscribe<EnemyDiedEvent>(OnDied);
        }

        private void OnDisable()
        {
            EventBus.Unsubscribe<EnemyDamagedEvent>(OnDamaged);
            EventBus.Unsubscribe<EnemyDiedEvent>(OnDied);
        }

        /// <summary>受击:打断当前状态,切到 Hit。</summary>
        private void OnDamaged(EnemyDamagedEvent evt)
        {
            if (!_initialized) return;
            ChangeState(EnemyStateType.Hit);
        }

        /// <summary>死亡:最高优先级,切到 Dead。</summary>
        private void OnDied(EnemyDiedEvent evt)
        {
            if (!_initialized) return;
            ChangeState(EnemyStateType.Dead);
        }
```

**✅ 预期结果**：编译 0 报错。

**❓ 常见问题**：
- 报 "EnemyDamagedEvent / EnemyDiedEvent 找不到" → 确认步骤 5① 的 using 加对了。
- 报 "HitState / DeadState 找不到" → 确认步骤 3、4 文件建在 `State/` 目录、命名空间 `Emberwild.AI.Enemy.State`。
- 注意：受击/死亡事件里怪物是 `EnemyDamagedEvent`/`EnemyDiedEvent`（不是玩家的 `CharacterDamagedEvent`），别订错。

## 步骤 6：Animator 自检（Any State 打断过渡）

`Shell.controller` 阶段一重建时已建好 Reaction 分区（`Take Damage` / `Die` 状态 + `TakeDamage` / `IsDead` 参数）。这里只需**自检**两条打断过渡：

1. 双击打开 `Shell.controller` → Animator 窗口。
2. 检查 **`Any State → Take Damage`** 过渡：条件 `TakeDamage`（Trigger），且 **Has Exit Time = false**、**Can Transition To Self = false**。
3. 检查 **`Any State → Die`** 过渡：条件 `IsDead == true`（Bool），且 **Has Exit Time = false**、**Can Transition To Self = false**。
4. `Die` 状态**不设出口**（终止态）。

**✅ 预期结果**：Animator 里能看到这两条从 Any State 出发的打断过渡。

**❓ 常见问题**：
- 受击动画自己打断自己（抽搐）→ 是 `Can Transition To Self` 没关，改成 false。
- 受击要等当前动画播完才切 → 是 `Has Exit Time` 还勾着，改成 false（否则失去"打断"意义）。

## 步骤 8：报错对照表

| 现象 | 原因 | 修法 |
| -- | -- | -- |
| 打怪不掉血、无反应 | 步骤 1 没改 / 事件没发 | 检查 `CombatAttribute` 是否整体替换 |
| 怪掉血但不播受击动画 | `EnemyBrain` 没订阅 / 没注册 Hit | 步骤 5④⑤ |
| 受击动画抽搐 | Any State 过渡 `Can Transition To Self` 没关 | 步骤 6 |
| 受击要等动画播完才响应 | `Has Exit Time` 还勾着 | 步骤 6 改 false |
| 死亡后尸体还在被打 | `IsDead` 没拦住 | 确认 `TakeDamage` 开头 `if (IsDead) return;` |
| 玩家被咬不播 GetHit | CharacterFeedback 没挂/引用空 | 检查 MC19 的 CharacterFeedback 组件（已确认挂了） |
| `NullReferenceException` 在 OnDamaged | 事件在 `_initialized` 之前触发 | 确认回调有 `if (!_initialized) return;` |
