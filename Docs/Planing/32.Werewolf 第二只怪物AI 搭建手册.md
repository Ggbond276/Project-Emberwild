# 阶段 1：设计 Werewolf Animator

纯 Unity 操作。产出一个能手动测试的 `Werewolf_AI.controller`。

## 1.1 盘点动画

路径：`Assets/Art/UnityPackage/Monsters/Monsters Ultimate Pack 02 Cute Series/Werewolf Cute Series/FBX/`

**用 14 个**：Idle、Walk、Run（In Place 版）、Look Left Right、Bite Attack、Left Slash、Right Slash、Smash Attack、Pounce Smash In Place、Jump Forward In Place、Projectile Attack、Cast Spell、Take Damage、Die

**排除 8 个**：

| 动画 | 排除原因 |
|---|---|
| 5 个 `W Root` | 带根位移，会和 `CustomNavAgent` 抢移动权 |
| `Jump In Place` | 原地跳，无战斗语义 |

|---|---|

## 1.5 MeleeCombo 子状态机

Create State → From New Sub-State Machine，命名 `MeleeCombo`，双击进入。

3 个状态：`Bite`(Bite Attack) / `LeftSlash`(Left Slash Attack) / `RightSlash`(Right Slash Attack)

2 条内部过渡：

| From | To | Has Exit Time | Exit Time | Duration |
|---|---|---|---|---|
| Bite | LeftSlash | ✅ | 0.8 | 0.1 |
| LeftSlash | RightSlash | ✅ | 0.8 | 0.1 |

`Bite` 设为子状态机默认状态，然后退出子状态机。

## 1.6 连过渡

**规则**：

| 过渡类型 | Has Exit Time | Duration |
|---|---|---|
| AnyState → 动作 | ❌ 取消 | 0 |
| 动作 → Locomotion | ✅ 勾选 | 0.1 |

**AnyState 出 9 条**（选中 AnyState 节点 → `+`）：

| 目标 | 条件 |
|---|---|
| Alert | Alert |
| MeleeCombo | Melee |
| Smash | Heavy |
| Pounce | Pounce |
| Leap | Leap |
| RangedAttack | RangedAttack |
| CastSpell | Spell |
| TakeDamage | TakeDamage |
| Death | IsDead = true |

> 顺序 = 优先级，**`Death` 必须放最后**。

**每条 AnyState 过渡都要**：取消 `Has Exit Time`、`Duration = 0`、取消 `Can Transition To Self`。

**动作 → Locomotion 出 8 条**（Death 不连出口）：全部勾 `Has Exit Time`，`Exit Time = 0.9`，`Duration = 0.1`。

## 3.1 新建 `EnemyAnimator.cs`

文件：`Assets/Scripts/AI/Enemy/EnemyAnimator/EnemyAnimator.cs`

```csharp
using System.Collections.Generic;
using Emberwild.Core.AppLog;
using UnityEngine;

namespace Emberwild.AI.Enemy.EnemyAnimator
{
    /// <summary>通用动画驱动，服务所有怪物。</summary>
    [DisallowMultipleComponent]
    public class EnemyAnimator : MonoBehaviour, IEnemyAnimator
    {
        [SerializeField] private Animator _animator;

        /// <summary>动作 → Animator 参数名，下标与 EnemyAction 顺序一致。</summary>
        private static readonly string[] ActionParameters =
        {
            "Melee",        // Melee
            "Heavy",        // Heavy
            "Pounce",       // Pounce
            "Leap",         // Leap
            "RangedAttack", // Ranged
            "Spell",        // Spell
            "Alert",        // Alert
            "TakeDamage",   // TakeDamage
        };

        /// <summary>状态 → Animator 参数名，下标与 EnemyStateFlag 顺序一致。</summary>
        private static readonly string[] StateParameters =
        {
            "Dash",     // Dash
            "Stance",   // Stance
        };

        private const string MoveSpeedParameter = "MoveSpeed";
        private const string DeadParameter = "IsDead";

        private int _moveSpeedHash;
        private int _deadHash;
        private int[] _actionHashes;
        private int[] _stateHashes;
        private readonly HashSet<string> _available = new HashSet<string>();

        private void Awake()
        {
            if (_animator == null) _animator = GetComponentInChildren<Animator>(true);
            if (_animator == null)
            {
                AppLog.Warning("Enemy", name + "：找不到 Animator");
                return;
            }

            AssertContractSize();

            _moveSpeedHash = Animator.StringToHash(MoveSpeedParameter);
            _deadHash = Animator.StringToHash(DeadParameter);
            _actionHashes = new int[ActionParameters.Length];
            _stateHashes = new int[StateParameters.Length];

            CollectParameters();
            LogCapabilities();
        }

        /// <summary>检查映射表长度与枚举数量是否一致。</summary>
        private static void AssertContractSize()
        {
            int actionCount = System.Enum.GetValues(typeof(EnemyAction)).Length;
            int stateCount = System.Enum.GetValues(typeof(EnemyStateFlag)).Length;

            if (ActionParameters.Length != actionCount)
                AppLog.Error("Enemy", "ActionParameters 长度 " + ActionParameters.Length
                    + " 与 EnemyAction 数量 " + actionCount + " 不一致");

            if (StateParameters.Length != stateCount)
                AppLog.Error("Enemy", "StateParameters 长度 " + StateParameters.Length
                    + " 与 EnemyStateFlag 数量 " + stateCount + " 不一致");
        }

        /// <summary>收集控制器里实际存在的参数。</summary>
        private void CollectParameters()
        {
            _available.Clear();
            var ps = _animator.parameters;
            for (int i = 0; i < ps.Length; i++) _available.Add(ps[i].name);
        }

        /// <summary>打印这只怪拥有哪些能力。</summary>
        private void LogCapabilities()
        {
            if (!_available.Contains(MoveSpeedParameter))
                AppLog.Warning("Enemy", name + "：缺少 MoveSpeed");

            if (!_available.Contains(DeadParameter))
                AppLog.Warning("Enemy", name + "：缺少 IsDead");

            var actions = new List<string>();
            for (int i = 0; i < ActionParameters.Length; i++)
                if (_available.Contains(ActionParameters[i]))
                    actions.Add(((EnemyAction)i).ToString());

            var states = new List<string>();
            for (int i = 0; i < StateParameters.Length; i++)
                if (_available.Contains(StateParameters[i]))
                    states.Add(((EnemyStateFlag)i).ToString());

            AppLog.Info("Enemy", name + "：动作 [" + string.Join(", ", actions)
                + "]  状态 [" + string.Join(", ", states) + "]");
        }

        /// <summary>设置移动强度，0~1。</summary>
        public void SetMoveSpeed(float normalizedSpeed)
        {
            if (_animator == null || !_available.Contains(MoveSpeedParameter)) return;
            _animator.SetFloat(_moveSpeedHash, Mathf.Clamp01(normalizedSpeed));
        }

        /// <summary>播放一次性动作。该怪没有此能力时静默跳过。</summary>
        public void PlayAction(EnemyAction action)
        {
            if (_animator == null) return;

            int index = (int)action;
            if (index < 0 || index >= ActionParameters.Length) return;

            string parameterName = ActionParameters[index];
            if (!_available.Contains(parameterName)) return;

            int hash = ResolveHash(_actionHashes, index, parameterName);
            if (hash == 0) return;

            _animator.ResetTrigger(hash);
            _animator.SetTrigger(hash);
        }

        /// <summary>开关可逆状态。该怪没有此能力时静默跳过。</summary>
        public void SetState(EnemyStateFlag state, bool active)
        {
            if (_animator == null) return;

            int index = (int)state;
            if (index < 0 || index >= StateParameters.Length) return;

            string parameterName = StateParameters[index];
            if (!_available.Contains(parameterName)) return;

            int hash = ResolveHash(_stateHashes, index, parameterName);
            if (hash == 0) return;

            _animator.SetBool(hash, active);
        }

        /// <summary>设置死亡状态。</summary>
        public void SetDead(bool dead)
        {
            if (_animator == null || !_available.Contains(DeadParameter)) return;
            _animator.SetBool(_deadHash, dead);
        }

        /// <summary>取缓存的参数 hash，首次调用时计算。</summary>
        private static int ResolveHash(int[] cache, int index, string parameterName)
        {
            int hash = cache[index];
            if (hash != 0) return hash;

            hash = Animator.StringToHash(parameterName);
            cache[index] = hash;
            return hash;
        }

        [ContextMenu("测试：近战")]
        private void TestMelee() => PlayAction(EnemyAction.Melee);

        [ContextMenu("测试：受击")]
        private void TestTakeDamage() => PlayAction(EnemyAction.TakeDamage);

        [ContextMenu("测试：冲刺开")]
        private void TestDashOn() => SetState(EnemyStateFlag.Dash, true);

        [ContextMenu("测试：冲刺关")]
        private void TestDashOff() => SetState(EnemyStateFlag.Dash, false);
    }
}
```

## 4.2 新建 `WerewolfStates.cs`

文件：`Assets/Scripts/AI/Enemy/State/WerewolfStates.cs`

```csharp
using Emberwild.AI.Enemy.EnemyAnimator;
using UnityEngine;

namespace Emberwild.AI.Enemy.State
{
    /// <summary>警戒：张望一次后转入追击。</summary>
    public class AlertState : IEnemyState
    {
        private float _endTime;

        public void OnEnter(EnemyBrain brain)
        {
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);
            brain.Animator.PlayAction(EnemyAction.Alert);

            brain.BB.HasAlerted = true;
            _endTime = Time.time + brain.AlertDuration;
        }

        public void OnUpdate(EnemyBrain brain)
        {
            if (Time.time >= _endTime)
                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
        }

        public void OnExit(EnemyBrain brain) { }
    }

    /// <summary>重击：慢速高伤，使用独立冷却。</summary>
    public class AttackHeavyState : IEnemyState
    {
        public void OnEnter(EnemyBrain brain)
        {
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);

            if (brain.BB.Target != null) brain.Agent.FaceTowards(brain.BB.Target.position);

            brain.Combat.DoAttack(EnemyAction.Heavy, brain.HeavyAttackDuration);
            brain.BB.LastHeavyTime = Time.time;
            brain.BB.LastAttackTime = Time.time;
        }

        public void OnUpdate(EnemyBrain brain)
        {
            if (!brain.Combat.IsAttacking)
                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
        }

        public void OnExit(EnemyBrain brain) { }
    }

    /// <summary>扑击：中距离突进并攻击。</summary>
    public class PounceState : IEnemyState
    {
        private Vector3 _direction;
        private float _endTime;

        public void OnEnter(EnemyBrain brain)
        {
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(1f);
            brain.Animator.PlayAction(EnemyAction.Pounce);

            _direction = ResolveForward(brain);
            brain.BB.LastPounceTime = Time.time;
            brain.BB.LastAttackTime = Time.time;
            brain.Combat.DoAttack(EnemyAction.Pounce);

            _endTime = Time.time + brain.PounceDuration;
        }

        public void OnUpdate(EnemyBrain brain)
        {
            brain.Agent.SetDirectVelocity(_direction, brain.PounceSpeed);

            if (Time.time >= _endTime)
                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
        }

        public void OnExit(EnemyBrain brain)
        {
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);
        }

        private static Vector3 ResolveForward(EnemyBrain brain)
        {
            if (brain.BB.Target == null) return brain.transform.forward;

            Vector3 dir = brain.BB.Target.position - brain.transform.position;
            dir.y = 0f;
            return dir.sqrMagnitude > 0.001f ? dir.normalized : brain.transform.forward;
        }
    }

    /// <summary>跃击：远距离跳跃并攻击。</summary>
    public class LeapState : IEnemyState
    {
        private Vector3 _direction;
        private float _endTime;

        public void OnEnter(EnemyBrain brain)
        {
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(1f);
            brain.Animator.PlayAction(EnemyAction.Leap);

            Vector3 dir = brain.BB.Target != null
                ? brain.BB.Target.position - brain.transform.position
                : brain.transform.forward;
            dir.y = 0f;
            _direction = dir.sqrMagnitude > 0.001f ? dir.normalized : brain.transform.forward;

            brain.BB.LastLeapTime = Time.time;
            brain.Combat.DoAttack(EnemyAction.Leap);

            _endTime = Time.time + brain.LeapDuration;
        }

        public void OnUpdate(EnemyBrain brain)
        {
            brain.Agent.SetDirectVelocity(_direction, brain.LeapSpeed);

            if (Time.time >= _endTime)
                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
        }

        public void OnExit(EnemyBrain brain)
        {
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);
        }
    }

    /// <summary>施法：播放施法动作，期间不可移动。</summary>
    public class CastSpellState : IEnemyState
    {
        private float _endTime;

        public void OnEnter(EnemyBrain brain)
        {
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);
            brain.Animator.PlayAction(EnemyAction.Spell);

            brain.BB.LastSpellTime = Time.time;
            _endTime = Time.time + brain.SpellDuration;
        }

        public void OnUpdate(EnemyBrain brain)
        {
            if (Time.time >= _endTime)
                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
        }

        public void OnExit(EnemyBrain brain) { }
    }
}
```

## 5.6 EnemyCombat 支持动作枚举

文件：`Assets/Scripts/AI/Enemy/EnemyCombat.cs`

```csharp
        /// <summary>发起攻击，返回是否成功发出。</summary>
        public bool DoAttack(EnemyAction action = EnemyAction.Melee, float duration = -1f)
        {
            if (IsAttacking) return false;

            float window = duration > 0f ? duration : _attackDuration;
            _attackEndTime = Time.time + window;

            Animator?.PlayAction(action);
            EventBus.Publish(new CharacterAttackHitEvent(_entity, ComboIndex));
            AppLog.Info("Combat", $"{name} 攻击 [{action}] 窗口={window}s");
            return true;
        }

        /// <summary>发起远程攻击，返回是否成功发出。</summary>
        public bool DoRangedAttack(Vector3 targetPos, EnemyAction action = EnemyAction.Ranged)
        {
            if (IsAttacking) return false;

            _attackEndTime = Time.time + _attackDuration;

            Animator?.PlayAction(action);
            EventBus.Publish(new CharacterAttackHitEvent(_entity, 1, targetPos));
            AppLog.Info("Combat", $"{name} 远程 [{action}] target={targetPos}");
            return true;
        }
```

同时改两个状态：

- `AttackMeleeState`：`DoAttack()` → `DoAttack(EnemyAction.Melee)`
- `AttackRangedState`：`DoRangedAttack(pos)` → `DoRangedAttack(pos, EnemyAction.Ranged)`，并在 `OnEnter` 里加 `brain.BB.LastRangedTime = Time.time;`

## 5.6.1 定身机制（攻击不能滑动）

### 问题

`Agent.Stop()` 只清一次速度，之后物理引擎继续模拟。怪物和玩家都是 Dynamic Rigidbody（质量各 1），
所以会互相推挤：攻击时被玩家推着走，追击时贴着玩家把玩家顶开。

### 解决

`CustomNavAgent` 增加移动锁：

```csharp
public void SetMotionLocked(bool locked)
```

- 锁定：清速度 + 冻结 `FreezePositionX/Z`（保留 Y 维持重力）+ 停止寻路
- 解锁：恢复原本的"只冻结旋转"约束
- 锁定期间 `SetDestination` / `SetDirectVelocity` 全部忽略

### 各状态怎么用

| 状态 | OnEnter | OnExit | 理由 |
|---|---|---|---|
| `AttackMelee` / `AttackRanged` / `AttackHeavy` | **锁** | **解** | 攻击必须完全定住 |
| `Hit` | **锁** | **解** | 受击被打退也要站住 |
| `CastSpell` / `Alert` | **锁** | **解** | 施法/张望不能移动 |
| `Idle` | **锁** | **解** | 站着时不该被推走 |
| `Dead` | **锁** | 不解 | 终态，永不解锁 |
| `Chase` | 解 | — | 移动状态，防御性解锁 |
| `Pounce` / `Leap` / `RollChase` | `Stop()`（不锁） | **解** | 需要位移，不能锁 |

> **新增状态时**：如果要站住 → `SetMotionLocked(true)`，`OnExit` 必须 `SetMotionLocked(false)`。
> 漏了解锁，怪物会永远定在原地不动。

### 还有一层：攻击窗口

状态退出由 `attackDuration` 决定。如果它比动画短，状态一结束就会切到 `Chase` 解锁并开始移动，
而动画还在播攻击后摇——视觉上就是"边打边走"。

**`attackDuration` 应 ≥ 咬击动画长度。** 查看方法：Animator 窗口点开 `MeleeCombo → Bite`，
Inspector 里的 Motion 显示 clip 时长。

Wolf 当前设为 `1.1`（Bite Attack 约 1.0 秒）。

### 字段含义

| 字段 | 含义 | 说明 |
|---|---|---|
| `ComboGroup` | 攻击组 | 必须等于 `CharacterDefine.SubType` |
| `ComboIndex` | 段号 | 同一组内唯一 |
| `DmgRate` | 伤害倍率 | 伤害 = `max(1, 攻击方AD × DmgRate − 防御方DEF)` |

| `Param1` | 形状参数 1 | 球：半径；矩形：宽（X）；扇形：半径 |

| 招式 | 用哪个 | 理由 |

| 近战 / 重击 / 扑击 / 跃击 | `2` 矩形 | 长条形，符合"挥爪"的形状 |
| 远程 | `1` 球形 | 判定中心在目标点，球形最省事 |
| 身前大范围横扫 | `3` 扇形 | 注意扇形只支持朝前的角度，不支持倾斜 |

| 完全没动画 | Console 的动作列表是否为空；`Animator.Controller` 是否是 `Werewolf_AI` |
| 某个动作不播 | 动作列表里有没有它 → 控制器参数名是否拼对 |
| 站着不动也不打 | `stoppingDistance` 是否 ≥ 2.2（应 < 2.2） |
| 疯狂连打 | 攻击分支是否配了 `CooldownAttackReady` |
| 打人没伤害 | `SubType` 是否等于 `ComboGroup`（**大小写敏感**）；`AttackDefine` 是否有该段 |
| Console 报"找不到武器 [X] 的第 [N] 段" | ①`SubType` 与 `ComboGroup` 拼写是否完全一致（含大小写）②该 `ComboIndex` 是否存在 |
| 伤害数值都一样 | `Attack Actions` 段号是否都填了 0 |
| Console 报"缺少 [X] 的段号映射" | `Attack Actions` 漏了该动作 |
| 一直张望 | `NotAlerted` 条件是否生效；`AlertState.OnEnter` 是否置 `HasAlerted` |
| 死后还能动 | `Death` 的 AnyState 过渡是否勾了 `Has Exit Time` |
| 数值不对 | Console 搜 "使用兜底数值" → `CharacterDefine.txt` 缺 TID |
| **只会站着 Idle，不追不打** | ①`EnemyPerception._targetLayer` 是否为空 ②`EnemyBrain` 的 `Config` 是否连上 ③行为树是否有 `HasTarget → Chase` 分支 |
| 玩家打不到它 | 怪物根节点 Layer 是否为 `Monster` |
| Console 报"状态 X 未注册" | `EnemyStateFactory` 漏注册；对比枚举值与注册行数 |
| 选了条件但没有参数框 | `ConditionMeta.ParamCount` 里漏了该条件 |
| 远程一直触发 | `AttackRangedState.OnEnter` 是否设了 `LastRangedTime` |

# 阶段 8：为什么现在还不该做通用框架

## 这次改动统计

```

```

## 动画层已经解决

`新建动画实现类` 是 **0**。Shell 和 Werewolf 共用 `EnemyAnimator`。

**前提是阶段 0 先把 Shell 的参数名统一了。** 顺序反了做不了。

## 但数据层没解决

| 文件 | 每加一只怪就要改 |
|---|---|
| `EnemyBlackboard` | +N 个时间戳字段 |
| `EnemyAIConfig` | +N 个参数 |
| `EnemyBrain` | +N 个属性（纯样板） |
| `BTNodeDef` | +N 个条件枚举 |
| `ConditionFactory` | +N 个 case（大量重复） |

**这 5 个文件改的方式和 Shell 那次一模一样。**

## 为什么现在不抽象

| 判断项 | 现状 |
|---|---|
| 动画层重复 | 已消除（1 个类） |
| 数据层重复 | 见过 2 次，**还看不清该抽什么** |
| 第 3 只怪可能推翻的假设 | "所有怪都有 Melee" / "所有怪都会移动" / "受击都停+硬直" / "死亡都关感知" |

**Rule of Three**：同一个重复写到第 3 次，才看得出哪些是本质的。
现在只有 2 只怪，按并集抽象会让 Shell 背 4 份死配置，按交集抽象又不够用。

## 第 3 只怪开始观察什么
