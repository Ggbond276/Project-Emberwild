## 阶段零：伤害事件补全（前置，打通"命中信息"管道）

**目标**：让"谁被打、打在哪、从哪个方向打"这些信息能通过事件传出来。这是特效/击退/闪光的共同数据源。

**为什么**：现在 `CombatAttribute.TakeDamage` 只传伤害值，事件里的 `FromDirection` 写死 `Vector3.zero`，特效不知道该在哪生成、击退不知道该往哪推。

### 步骤 0.1：给两个受伤事件加「命中点」字段

**文件** `Assets/Scripts/Core/Events/CharacterDamagedEvent.cs`，改为：

### 步骤 0.2：`TakeDamage` 接收命中点与方向

**文件** `Assets/Scripts/Combat/CombatAttribute.cs`，把方法签名和两个事件发布改成：

```csharp
public void TakeDamage(float damageAmount, Vector3 hitPoint, Vector3 fromDirection)
{
    if (IsDead) return;
    if (IsHidden) damageAmount *= 0.5f;

    CurrentHp = Mathf.Max(0, CurrentHp - damageAmount);
    AppLog.Info("Combat", $"{gameObject.name} 受到 {damageAmount:F1} 伤害, 剩余 HP: {CurrentHp:F1}");

    if (CurrentHp <= 0)
    {
        IsDead = true;
        PublishDiedEvent();
    }
    else
    {
        PublishDamagedEvent(damageAmount, hitPoint, fromDirection);
    }
}

private void PublishDamagedEvent(float damage, Vector3 hitPoint, Vector3 fromDirection)
{
    if (_entity == null) return;
    if (_entity.Faction == FactionType.Player)
        EventBus.Publish(new CharacterDamagedEvent(damage, CurrentHp, fromDirection, hitPoint));
    else
        EventBus.Publish(new EnemyDamagedEvent(_entity, damage, CurrentHp, fromDirection, hitPoint));
}
```

### 步骤 0.3：判定处算出方向与命中点

**文件** `Assets/Scripts/Combat/CombatDetector.cs`，`ProcessHits` 里把最后两行改为：

```csharp
float finalDamage = DamageCalculator.Calculate(attackerAttr, defenderAttr, atkDefine.DmgRate);

// 计算攻击来向(从受害者指向命中点),压平 Y 用于水平击退
Vector3 fromDir = center - defenderAttr.transform.position;
fromDir.y = 0f;
if (fromDir.sqrMagnitude > 0.0001f) fromDir.Normalize();

defenderAttr.TakeDamage(finalDamage, center, fromDir);
```

> 说明：`center` 就是命中判定中心（步骤 0 之前的 `center` 变量），把它当作"命中点"传给事件；`fromDir` 是"攻击来向"，击退时取反方向就是"被推走的方向"。

## 阶段一：顿帧 Hit-Stop（最易）

**目标**：命中瞬间整个游戏时间短暂"冻住"一下，制造打击点。

**原理**：`Time.timeScale` 是全局时间倍率，设成 0 就全冻结。命中时拉低，几十毫秒后恢复 1。

### 步骤 1.1：新建 `HitStopController.cs`

放 `Assets/Scripts/Feedback/`，命名空间 `Emberwild.Feedback`：

```csharp
using Emberwild.Core.Events;
using Emberwild.Core.Singleton;
using UnityEngine;

namespace Emberwild.Feedback
{
    /// <summary>顿帧：命中瞬间全局时间短暂冻结。继承项目已有的 MonoSingleton 单例基类,挂在 GameFeel 物体上。</summary>
    public class HitStopController : MonoSingleton<HitStopController>
    {
        [Tooltip("顿帧时长(秒)")]
        [SerializeField] private float _duration = 0.05f;

        [Tooltip("顿帧期间的时间倍率(0=完全冻结)")]
        [SerializeField, Range(0f, 1f)] private float _timeScale = 0f;

        private float _endTime;

        private void OnEnable()
        {
            EventBus.Subscribe<EnemyDamagedEvent>(OnEnemyHit);
            EventBus.Subscribe<CharacterDamagedEvent>(OnPlayerHit);
        }

        private void OnDisable()
        {
            EventBus.Unsubscribe<EnemyDamagedEvent>(OnEnemyHit);
            EventBus.Unsubscribe<CharacterDamagedEvent>(OnPlayerHit);
        }

        private void OnEnemyHit(EnemyDamagedEvent evt) => Trigger();
        private void OnPlayerHit(CharacterDamagedEvent evt) => Trigger();

        public void Trigger()
        {
            Time.timeScale = _timeScale;
            _endTime = Time.unscaledTime + _duration;   // 用 unscaledTime 计时,否则顿帧把自己也冻住
        }

        private void Update()
        {
            // 顿帧结束,恢复时间(仅当确实在顿帧时)
            if (Time.timeScale != 1f && Time.unscaledTime >= _endTime)
                Time.timeScale = 1f;
        }
    }
}
```

> **单例说明**：项目已有两个单例基类（`Assets/Scripts/Core/Singleton/`）——`Singleton<T>`（普通 C# 单例，如 `CombatDetector`）和 `MonoSingleton<T>`（MonoBehaviour 场景单例，自动 `DontDestroyOnLoad` 并销毁重复实例）。`HitStopController` 需要挂场景、每帧计时，所以继承 `MonoSingleton<HitStopController>`，`Instance` 由基类提供，**不要自己写静态字段和 Awake 赋值**。

### 步骤 1.2：挂载

把 `HitStopController` 挂到场景的 `GameFeel` 物体上，参数保持默认（时长 0.05、倍率 0）。

### ✅ 验证阶段一

打怪瞬间画面"卡一下"，之后一切恢复。多打几下，确认连续命中也能正常恢复（不会卡死）。

### 🔧 调优方向 / 坑点

- **太长卡顿、太短没感**：0.03~0.06 秒之间调；重击/暴击可以更长（后续可加"按伤害分级"）。
- **倍率 0 vs 0.1**：0 最"硬"，0.1 保留一丝动感。个人口味。
- **坑**：`Time.timeScale` 是全局的，顿帧期间 UI 动画、物理、粒子都会一起变慢——**这是预期**，别当 bug。
- **坑**：计时绝不能用 `Time.deltaTime`（顿帧时它=0，永远到不了结束条件），一定用 `Time.unscaledTime`。

## 阶段二：震屏 Camera Shake（易）

**目标**：命中/被命中时镜头做衰减随机抖动。

**原理**：用"创伤值 trauma"模型（GDC《Juice it or lose it》经典做法）——命中给 trauma 加值，每帧衰减，震动幅度 = trauma² × 基础强度，位置用 Perlin 噪声取连续随机值（比纯随机更平滑）。

### 步骤 2.1：新建 `CameraShake.cs`

放 `Assets/Scripts/Feedback/`：

```csharp
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.Feedback
{
    /// <summary>震屏:命中时镜头衰减抖动。挂 Main Camera,执行顺序放在 CameraController 之后。</summary>
    [DefaultExecutionOrder(100)]
    public class CameraShake : MonoBehaviour
    {
        [Tooltip("最大位移偏移(米)")]
        [SerializeField] private float _maxOffset = 0.2f;

        [Tooltip("最大滚转角度(度)")]
        [SerializeField] private float _maxAngle = 2f;

        [Tooltip("每秒衰减量(越大越快停)")]
        [SerializeField] private float _decay = 1.5f;

        private float _trauma; // 创伤值 0~1

        private void OnEnable()
        {
            EventBus.Subscribe<EnemyDamagedEvent>(OnEnemyHit);
            EventBus.Subscribe<CharacterDamagedEvent>(OnPlayerHit);
        }
        private void OnDisable()
        {
            EventBus.Unsubscribe<EnemyDamagedEvent>(OnEnemyHit);
            EventBus.Unsubscribe<CharacterDamagedEvent>(OnPlayerHit);
        }

        private void OnEnemyHit(EnemyDamagedEvent evt) => AddTrauma(0.5f);
        private void OnPlayerHit(CharacterDamagedEvent evt) => AddTrauma(0.4f);

        public void AddTrauma(float amount) => _trauma = Mathf.Clamp01(_trauma + amount);

        private void LateUpdate()
        {
            if (_trauma <= 0.0001f) { _trauma = 0f; return; }

            // 用 unscaledDeltaTime:顿帧期间震动也要继续
            _trauma = Mathf.Max(0f, _trauma - _decay * Time.unscaledDeltaTime);
            float shake = _trauma * _trauma; // 平方让衰减更"戛然而止"

            float t = Time.unscaledTime * 20f; // 20 是噪声频率
            Vector3 offset = new Vector3(
                (Mathf.PerlinNoise(0f, t) - 0.5f) * 2f * _maxOffset * shake,
                (Mathf.PerlinNoise(100f, t) - 0.5f) * 2f * _maxOffset * shake,
                0f);
            float roll = (Mathf.PerlinNoise(200f, t) - 0.5f) * 2f * _maxAngle * shake;

            // 叠加在 CameraController 的跟随结果上(本组件执行顺序在其后)
            transform.position += offset;
            transform.rotation *= Quaternion.Euler(0f, 0f, roll);
        }
    }
}
```

### 步骤 2.2：挂载 + 执行顺序

1. 把 `CameraShake` 挂到 `Main Camera`。
2. 选中 `CameraShake` 脚本 → 右上角菜单 → **Edit → Project Settings → Script Execution Order** → 点 `+` 添加 `CameraShake`，把值设成 **100**（默认 `CameraController` 是 0），保证它在跟随之后执行、叠加不冲突。

### ✅ 验证阶段二

打怪命中瞬间镜头轻微抖动，抖动平滑衰减、无跳变、无持续漂移。

### 🔧 调优 / 坑点

- **强度**：`_maxOffset` 0.1~0.3 米；被重击可加大。
- **频率**：`t` 的系数 20 越大抖得越快越"碎"，越小越"晃"。
- **坑**：必须 `unscaledDeltaTime`，否则顿帧期间震动被冻住。
- **坑**：忘了设 Script Execution Order 会导致震动被 `CameraController` 的 `LookAt` 覆盖，看起来"不震"或"跳变"。

## 阶段三：音效 SFX（易，需素材）

**目标**：命中/受击播放音效。

**需准备素材**：命中音效、受击音效各 1 个（`.wav`/`.ogg`，短促 <1 秒），放进 `Assets/Audio/`（新建目录）。

### 步骤 3.1：新建 `HitAudioPlayer.cs`

```csharp
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.Feedback
{
    /// <summary>命中音效。挂 GameFeel,自带 AudioSource。</summary>
    [RequireComponent(typeof(AudioSource))]
    public class HitAudioPlayer : MonoBehaviour
    {
        [SerializeField] private AudioSource _source;
        [Tooltip("打到怪的音效")] [SerializeField] private AudioClip _hitClip;
        [Tooltip("自己被打的音效")] [SerializeField] private AudioClip _hurtClip;

        private void Awake()
        {
            if (_source == null) _source = GetComponent<AudioSource>();
        }

        private void OnEnable()
        {
            EventBus.Subscribe<EnemyDamagedEvent>(OnEnemyHit);
            EventBus.Subscribe<CharacterDamagedEvent>(OnPlayerHit);
        }
        private void OnDisable()
        {
            EventBus.Unsubscribe<EnemyDamagedEvent>(OnEnemyHit);
            EventBus.Unsubscribe<CharacterDamagedEvent>(OnPlayerHit);
        }

        private void OnEnemyHit(EnemyDamagedEvent evt) => Play(_hitClip);
        private void OnPlayerHit(CharacterDamagedEvent evt) => Play(_hurtClip);

        private void Play(AudioClip clip)
        {
            if (clip == null || _source == null) return;
            _source.pitch = Random.Range(0.9f, 1.1f);   // 随机音高,减少重复感
            _source.PlayOneShot(clip);
        }
    }
}
```

### 步骤 3.2：挂载 + 拖素材

1. 挂到 `GameFeel`，Unity 会自动加 `AudioSource`。
2. 把两个音效素材拖进 `Hit Clip` / `Hurt Clip`。

### ✅ 验证阶段三

打怪有命中声、被打有受击声；连续快速命中不爆音、不卡顿。

### 🔧 调优 / 坑点

- **随机音高**（pitch 0.9~1.1）是消除"电子合成重复感"的关键，别省。
- **坑**：`PlayOneShot` 可以叠加多次，但 pitch 是 AudioSource 级的、会统一作用于所有声音；要更精细可上"多个 AudioSource 轮流播"或 AudioMixer。
- **坑**：没有素材时先随便拖个 Unity 自带的临时音效占位，跑通逻辑再替换。

## 阶段四：打击特效 VFX（中）

**目标**：命中点爆出火花/光效。

**需准备素材**：一个命中粒子预制体。两个办法二选一：
- 复用美术包里现成的 `Assets/Art/UnityPackage/.../FX Spark.prefab`，复制一份到 `Assets/Prefabs/Effects/`。
- 或自己新建：`Hierarchy 右键 → Effects → Particle System`，把生命周期调成 0.3 秒左右，另存为 prefab。

### 步骤 4.1：新建 `HitVfxSpawner.cs`

```csharp
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.Feedback
{
    /// <summary>打击特效:在命中点生成粒子。挂 GameFeel。</summary>
    public class HitVfxSpawner : MonoBehaviour
    {
        [Tooltip("命中粒子预制体")] [SerializeField] private GameObject _hitEffectPrefab;

        private void OnEnable()
        {
            EventBus.Subscribe<EnemyDamagedEvent>(OnEnemyHit);
            EventBus.Subscribe<CharacterDamagedEvent>(OnPlayerHit);
        }
        private void OnDisable()
        {
            EventBus.Unsubscribe<EnemyDamagedEvent>(OnEnemyHit);
            EventBus.Unsubscribe<CharacterDamagedEvent>(OnPlayerHit);
        }

        private void OnEnemyHit(EnemyDamagedEvent evt) => Spawn(evt.HitPoint, evt.FromDirection);
        private void OnPlayerHit(CharacterDamagedEvent evt) => Spawn(evt.HitPoint, evt.FromDirection);

        private void Spawn(Vector3 position, Vector3 direction)
        {
            if (_hitEffectPrefab == null) return;
            // 朝向攻击来向,让火花喷向被打的方向
            Quaternion rot = direction.sqrMagnitude > 0.0001f
                ? Quaternion.LookRotation(direction, Vector3.up)
                : Quaternion.identity;
            var go = Instantiate(_hitEffectPrefab, position, rot);
            Destroy(go, 1.5f); // 兜底回收(粒子本身也会自动结束)
        }
    }
}
```

### 步骤 4.2：挂载 + 拖 prefab

挂到 `GameFeel`，把命中粒子 prefab 拖进 `Hit Effect Prefab`。

### ✅ 验证阶段四

打怪时命中点（怪身体被击中的位置）爆出火花，位置准确、粒子自动消失。

### 🔧 调优 / 坑点

- **位置偏**：确认 `center`（阶段零的命中点）是你想要的位置；近战判定中心在 `forward * OffsetZ`，远程在目标点。
- **粒子生命周期**：0.2~0.4 秒合适；太长会"拖泥带水"。
- **坑**：频繁 `Instantiate` 会产生 GC 卡顿——本阶段先简单实现，量大了再上**对象池**（池化方向：预热 N 个粒子、取用/归还，见附录）。

## 阶段五：击退 Knockback（中难）

**目标**：被打的一方沿攻击方向被推开，衰减自然。

**原理**：给移动组件加一个"击退速度信箱"，击退期间**优先于**寻路/移动输入写入速度，随时间衰减归零后交还控制权。

### 步骤 5.1：玩家侧——`CharacterLocomotionMotor` 加击退

**文件** `Assets/Scripts/Character/CharacterLocomotionMotor.cs`，加字段和方法：

```csharp
// 击退状态
private Vector3 _knockbackVelocity;
private float _knockbackTotal;
private float _knockbackRemaining;

/// <summary>施加击退:velocity 为水平击退速度向量,duration 为持续秒数。</summary>
public void ApplyKnockback(Vector3 velocity, float duration)
{
    _knockbackVelocity = velocity;
    _knockbackTotal = duration;
    _knockbackRemaining = duration;
}
```

然后把 `FixedUpdate` 里合并速度的那段（`var v = _rb.velocity; ...`）改成：

```csharp
var v = _rb.velocity;

if (_knockbackRemaining > 0f)
{
    // 击退期间:击退速度优先,随时间线性衰减
    _knockbackRemaining -= Time.fixedDeltaTime;
    float t = _knockbackRemaining > 0f ? _knockbackRemaining / _knockbackTotal : 0f;
    v.x = _knockbackVelocity.x * t;
    v.z = _knockbackVelocity.z * t;
}
else
{
    v.x = DesiredHorizontalVelocity.x;
    v.z = DesiredHorizontalVelocity.z;
}
ApplyVelocity(v);
```

### 步骤 5.2：怪物侧——`CustomNavAgent` 加击退

**文件** `Assets/Scripts/AI/Pathfinding/CustomNavAgent.cs`，加字段和方法：

```csharp
private Vector3 _knockbackVelocity;
private float _knockbackTotal;
private float _knockbackRemaining;

/// <summary>施加击退:打断当前寻路,沿 velocity 后退 duration 秒。</summary>
public void ApplyKnockback(Vector3 velocity, float duration)
{
    _knockbackVelocity = velocity;
    _knockbackTotal = duration;
    _knockbackRemaining = duration;
    _hasDestination = false;   // 打断寻路
    _currentPath = null;
}
```

把 `FixedUpdate` 开头改成：

```csharp
void FixedUpdate()
{
    // 击退优先于寻路
    if (_knockbackRemaining > 0f)
    {
        _knockbackRemaining -= Time.fixedDeltaTime;
        float t = _knockbackRemaining > 0f ? _knockbackRemaining / _knockbackTotal : 0f;
        _rb.velocity = new Vector3(_knockbackVelocity.x * t, _rb.velocity.y, _knockbackVelocity.z * t);
        return;
    }

    if (!_hasDestination) return;
    // ...原有寻路逻辑不变
}
```

### 步骤 5.3：触发组件（谁被打就推谁）

新建两个文件（放 `Assets/Scripts/Feedback/`）：

**`PlayerKnockback.cs`**（挂玩家）：

```csharp
using Emberwild.Character;
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.Feedback
{
    public class PlayerKnockback : MonoBehaviour
    {
        [SerializeField] private CharacterLocomotionMotor _motor;
        [Tooltip("击退速度(米/秒)")] [SerializeField] private float _force = 4f;
        [Tooltip("击退持续(秒)")] [SerializeField] private float _duration = 0.15f;

        private void OnEnable() => EventBus.Subscribe<CharacterDamagedEvent>(OnDamaged);
        private void OnDisable() => EventBus.Unsubscribe<CharacterDamagedEvent>(OnDamaged);

        private void OnDamaged(CharacterDamagedEvent evt)
        {
            if (_motor == null) return;
            Vector3 dir = -evt.FromDirection; // 击退方向 = 攻击来向的反方向
            _motor.ApplyKnockback(dir * _force, _duration);
        }
    }
}
```

**`EnemyKnockback.cs`**（挂怪物 prefab）：

```csharp
using Emberwild.AI.Enemy;
using Emberwild.AI.Pathfinding;
using Emberwild.Combat;
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.Feedback
{
    public class EnemyKnockback : MonoBehaviour
    {
        [SerializeField] private EnemyEntity _entity;
        [SerializeField] private CustomNavAgent _agent;
        [Tooltip("击退速度(米/秒)")] [SerializeField] private float _force = 5f;
        [Tooltip("击退持续(秒)")] [SerializeField] private float _duration = 0.2f;

        private void OnEnable() => EventBus.Subscribe<EnemyDamagedEvent>(OnDamaged);
        private void OnDisable() => EventBus.Unsubscribe<EnemyDamagedEvent>(OnDamaged);

        private void OnDamaged(EnemyDamagedEvent evt)
        {
            // 只响应"自己"被打(多怪各自独立)
            if (_entity == null || evt.Victim != (ICombatEntity)_entity) return;
            if (_agent == null) return;
            Vector3 dir = -evt.FromDirection;
            _agent.ApplyKnockback(dir * _force, _duration);
        }
    }
}
```

### 步骤 5.4：挂载

- `PlayerKnockback` 挂玩家，拖 `CharacterLocomotionMotor`。
- `EnemyKnockback` 挂怪物 prefab，拖 `EnemyEntity` 和 `CustomNavAgent`。

### ✅ 验证阶段五

打怪时怪沿攻击方向后退一小段、衰减自然，之后恢复追击；玩家被咬也会被推后。

### 🔧 调优 / 坑点

- **力度**：`_force`（速度）× `_duration`（时间）共同决定推多远。太重会"飘"，太轻没感。
- **坑（最大）**：移动组件每帧用 `DesiredHorizontalVelocity` / 寻路覆盖 velocity，所以击退必须**在同一处优先判断**，否则被覆盖看不到效果。
- **坑**：击退方向要压平 Y（阶段零已压平），否则会把人推上天。
- **进阶**：击退期间可顺带锁移动/攻击（怪物 `EnemyBrain` 已有 `HitState` 硬直会自然打断）。

## 阶段六：受击闪光 Hit Flash（最难，含 shader）

**目标**：被打的一方身体短暂闪白/闪红后快速消退。

### 6.1 先补 shader 基础（零基础耐心看）

**① shader 是什么**：跑在 **GPU** 上的小程序，决定画面里每个像素最终是什么颜色。Unity 里写 shader 用的是 **HLSL/Cg** 语法。

**② 渲染管线两条路**：
- **顶点着色器**：处理模型的每个顶点（位置、法线），算出它们在屏幕上的位置。
- **片元着色器（像素着色器）**：处理屏幕上每个像素，算出最终颜色。**"受击闪白"要改的就是片元着色器的输出颜色**。

**③ Unity 的 Surface Shader（本阶段用这个）**：Unity 提供的一种**简化写法**，你只需要写一个 `surf` 函数描述"这个表面是什么颜色"，Unity 自动帮你生成顶点/片元着色器 + 光照。适合"给物体加一点自定义颜色逻辑"的场景，不用从零写完整管线。

**④ 材质（Material）vs shader**：
- **shader** = 程序（"怎么算颜色"）。
- **材质** = 填好参数的 shader 实例（"这个物体用它，贴图是这张、颜色是这个"）。
- 同一个 shader 可以有很多个材质；同一个材质可以被很多物体共用。

**⑤ Properties（属性）**：shader 顶部 `Properties { ... }` 里声明的、暴露给材质面板的可调参数。我们要加一个 `_HitFlashAmount` 控制闪白强度。

**⑥ MaterialPropertyBlock（关键，记住它）**：Unity 提供的"**运行时临时改材质属性**"的机制。它只影响**当前这一帧的渲染**，**不会修改材质资源本身、也不会为每个物体创建新材质实例**——所以 10 只怪共用一份材质，也能各自独立闪白、互不影响。

> 一个必须认识的现象：**材质变紫红色（magenta）= shader 编译报错**。这是 Unity 的"错误材质"，看到它就说明 shader 代码写错了，去 Console 看报错行。

### 6.2 方案 A（不写 shader，先用起来）

如果你的怪物/角色材质用的是 **Standard Shader** 且开了 **Emission**（自发光），可以不用写 shader：

1. 选中材质，在 Inspector 勾选 **Emission**，给个黑色 Emission 颜色。
2. 受击时用 `MaterialPropertyBlock` 把 `_EmissionColor` 拉高，衰减。

脚本（`HitFlashEmission.cs`）：

```csharp
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.Feedback
{
    public class HitFlashEmission : MonoBehaviour
    {
        [SerializeField] private Renderer[] _renderers;
        [SerializeField] private float _decay = 8f;
        private MaterialPropertyBlock _mpb;
        private float _amount;
        private static readonly int EmissionId = Shader.PropertyToID("_EmissionColor");

        private void Awake()
        {
            _mpb = new MaterialPropertyBlock();
            if (_renderers == null || _renderers.Length == 0)
                _renderers = GetComponentsInChildren<Renderer>();
        }

        private void OnEnable() => EventBus.Subscribe<EnemyDamagedEvent>(OnHit);
        private void OnDisable() => EventBus.Unsubscribe<EnemyDamagedEvent>(OnHit);
        private void OnHit(EnemyDamagedEvent evt) => _amount = 1f;

        private void Update()
        {
            if (_amount <= 0f) return;
            _amount = Mathf.Max(0f, _amount - _decay * Time.unscaledDeltaTime);
            _mpb.SetColor(EmissionId, Color.white * _amount);
            foreach (var r in _renderers) r.SetPropertyBlock(_mpb);
        }
    }
}
```

**缺点**：视觉偏"发光"而非"闪白"，且必须材质开了 Emission。

### 6.3 方案 B（写 shader，精确闪白，推荐掌握）

#### 步骤 6.3.1：写闪白 shader

`Assets/Scripts/Feedback/` 下新建文件 `HitFlash.shader`：

```hlsl
Shader "Emberwild/HitFlash"
{
    Properties
    {
        _MainTex ("Base Texture", 2D) = "white" {}
        _Color ("Base Color", Color) = (1,1,1,1)
        _HitFlashColor ("Hit Flash Color", Color) = (1,1,1,1)
        _HitFlashAmount ("Hit Flash Amount", Range(0,1)) = 0
    }
    SubShader
    {
        Tags { "RenderType"="Opaque" }
        LOD 200

        CGPROGRAM
        #pragma surface surf Lambert

        sampler2D _MainTex;
        fixed4 _Color;
        fixed4 _HitFlashColor;
        float _HitFlashAmount;

        struct Input
        {
            float2 uv_MainTex;
        };

        void surf (Input IN, inout SurfaceOutput o)
        {
            fixed4 c = tex2D(_MainTex, IN.uv_MainTex) * _Color;
            // 核心:按 _HitFlashAmount 把闪白颜色混合进最终颜色
            c.rgb = lerp(c.rgb, _HitFlashColor.rgb, _HitFlashAmount);
            o.Albedo = c.rgb;
            o.Alpha = c.a;
        }
        ENDCG
    }
    FallBack "Diffuse"
}
```

**逐行讲**：
- `Properties`：声明 4 个可调参数（贴图、底色、闪白颜色、闪白强度）。
- `#pragma surface surf Lambert`：用 Unity 的 Surface Shader 简化管线，`surf` 是我们要写的表面函数，`Lambert` 是简单漫反射光照。
- `surf`：对每个像素，先取贴图 × 底色，再用 `lerp`（线性插值）把颜色往 `_HitFlashColor` 靠拢，靠拢程度由 `_HitFlashAmount` 决定。`_HitFlashAmount=0` 时是原色，`=1` 时完全变成闪白。
- `lerp(a, b, t)` = `a + (b - a) * t`，`t=0` 返回 a、`t=1` 返回 b。

#### 步骤 6.3.2：把材质换成这个 shader

选中怪物材质（如 `Assets/Art/Material/Enemy.mat`），在 Inspector 顶部把 **Shader** 从原来的（Standard 等）改成 **Emberwild/HitFlash**。贴图保持不变。

> ⚠️ 换成 Lambert 后光照比 Standard 简单（没有 PBR 高光），卡通风格怪物一般影响不大；若要保留 PBR，可把 `#pragma surface surf Lambert` 换成 `#pragma surface surf Standard fullforwardshadows` 并相应改写（进阶，本阶段不展开）。

#### 步骤 6.3.3：写驱动闪光的脚本

`HitFlash.cs`（放 `Assets/Scripts/Feedback/`）：

```csharp
using Emberwild.AI.Enemy;
using Emberwild.Combat;
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.Feedback
{
    /// <summary>受击闪光:被打时身体闪白并快速消退。挂怪物 prefab(玩家同理可挂)。</summary>
    public class HitFlash : MonoBehaviour
    {
        [SerializeField] private EnemyEntity _entity;      // 用于判断"是不是我"
        [SerializeField] private Renderer[] _renderers;    // 要闪的网格(留空自动找子级)
        [SerializeField] private float _decay = 8f;        // 每秒衰减
        [SerializeField] private Color _flashColor = Color.white;

        private MaterialPropertyBlock _mpb;
        private float _amount;
        private static readonly int AmountId = Shader.PropertyToID("_HitFlashAmount");
        private static readonly int ColorId = Shader.PropertyToID("_HitFlashColor");

        private void Awake()
        {
            _mpb = new MaterialPropertyBlock();
            if (_renderers == null || _renderers.Length == 0)
                _renderers = GetComponentsInChildren<Renderer>();
        }

        private void OnEnable() => EventBus.Subscribe<EnemyDamagedEvent>(OnDamaged);
        private void OnDisable() => EventBus.Unsubscribe<EnemyDamagedEvent>(OnDamaged);

        private void OnDamaged(EnemyDamagedEvent evt)
        {
            if (_entity == null || evt.Victim != (ICombatEntity)_entity) return; // 只闪自己
            _amount = 1f;
        }

        private void Update()
        {
            if (_amount <= 0f) return;
            _amount = Mathf.Max(0f, _amount - _decay * Time.unscaledDeltaTime);
            _mpb.SetColor(ColorId, _flashColor);
            _mpb.SetFloat(AmountId, _amount);
            foreach (var r in _renderers)
                r.SetPropertyBlock(_mpb);
        }
    }
}
```

> 玩家受击闪光同理：挂一个只订阅 `CharacterDamagedEvent` 的版本（玩家唯一，无需 Victim 判断）。

#### 步骤 6.3.4：挂载

挂到怪物 prefab，拖 `EnemyEntity`；`Renderers` 留空（自动找子级所有 Renderer）。

### ✅ 验证阶段六

打怪瞬间怪身体闪白、约 0.1~0.2 秒快速消退；**刷多只怪，打其中一只只有它闪，其它不闪**（这是 `Victim` 判断 + MPB 的作用）。

### 🔧 调优 / 坑点

- **消退速度**：`_decay` 越大闪得越快（8 约 0.12 秒归零；4 约 0.25 秒）。
- **颜色**：闪白最通用；闪红更适合"被打"（可把 `_flashColor` 设成浅红）。
- **坑（最大）**：忘了把材质 shader 换成 `Emberwild/HitFlash`，`SetPropertyBlock` 设 `_HitFlashAmount` 不会生效（材质里没这个属性），看起来"什么都不发生"。
- **坑**：`MaterialPropertyBlock` 是每帧临时覆盖，**不会**污染材质资源，所以多怪独立闪是天然成立的；不要用 `renderer.material`（会克隆材质实例、内存泄漏）。
- **坑**：材质变紫红色 = shader 报错，去 Console 看哪一行语法错了。
- **坑**：`GetComponentsInChildren<Renderer>()` 会包含所有子级 Renderer（含武器、配件），都要设 MPB，否则有的部位不闪。
