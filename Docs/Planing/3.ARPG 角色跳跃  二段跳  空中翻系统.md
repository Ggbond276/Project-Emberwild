# Stage 3:角色跳跃 / 二段跳 / 空中翻系统

> 实现目标:跳跃 + 二段跳 + 空中翻(aerial spin/roll)。Sprint 已实现,本阶段不修改。
> **不**包含地面四向翻滚 / 闪避 / 攻击 / 受击等其它系统。

---

## 一、目标与操作

```text
- 地面按 A:跳跃,播 JumpStart → JumpAir
- 空中再按 A:触发"二段跳 + 空中翻"组合动作
  即:JumpAir_Double → JumpAir_Spin(由 DoubleJump trigger 触发,自动串接)
- 落地后 jump count 归零,可再次一段跳
- 跳跃中可继续推 LS 水平移动(摄像机相对方向不变)
- 落地判定基于 Rigidbody / Collider 物理接触,非动画时间
- 完整动作链:
  Locomotion → JumpStart → JumpAir → JumpAir_Double → JumpAir_Spin → JumpEnd → Locomotion
- 关键:DoubleJump 与 JumpAir_Spin 视为一个**组合动作序列**,中间无玩家输入
- 提前落地(动作链未完):任意空中 State 遇到 IsGrounded=true 立刻转 JumpEnd → Locomotion
```

## 三、Animator 配置(由用户在 Unity Editor 完成)

### 3.1 新增参数

| 参数名 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `Jump` | Trigger | false | 一段跳触发(地面按 A) |
| `DoubleJump` | Trigger | false | 触发"二段跳 + 空中翻"组合(空中按 A);**不**直接路由到单独 State,需配合 IsGrounded 条件 |
| `IsGrounded` | Bool | true | 地面状态(由代码每帧同步) |

> 只用 3 个参数:`Jump` / `DoubleJump` / `IsGrounded`。**不**新增 Spin 专用参数 — Spin 与 DoubleJump 视为同一组合动作。

### 3.2 新增 State(在 `Player_MVP.controller` 中创建)

| State 名 | Motion 路径 | 用途 |
|---|---|---|
| `JumpStart` | `.../SwordAndShield/InPlace/JumpStart_Normal_InPlace_SwordAndShield.fbx` | 起跳 |
| `JumpAir` | `.../SwordAndShield/InPlace/JumpAir_Normal_InPlace_SwordAndShield.fbx` | 一段跳空中 |
| `JumpAir_Double` | `.../SwordAndShield/InPlace/JumpAir_Double_InPlace_SwordAndShield.fbx` | 二段跳动作(短,2 帧过渡) |
| `JumpAir_Spin` | `.../SwordAndShield/InPlace/JumpAir_Spin_InPlace_SwordAndShield.fbx` | 空中翻(继 DoubleJump 之后) |
| `JumpEnd` | `.../SwordAndShield/InPlace/JumpEnd_Normal_InPlace_SwordAndShield.fbx` | 落地 |

### 3.3 状态转移(共 8 条,精确配置)

| From | To | Condition | HasExitTime | Exit Time | Duration |
|---|---|---|---|---|---|
| `Locomotion` | `JumpStart` | `Jump` && `IsGrounded` | No | — | 0.05 |
| `JumpStart` | `JumpAir` | (无) | Yes | 0.9 | 0.1 |
| `JumpAir` | `JumpEnd` | `IsGrounded` | No | — | 0.1 |
| `JumpAir` | `JumpAir_Double` | `DoubleJump` && `!IsGrounded` | No | — | 0.05 |
| `JumpAir_Double` | `JumpAir_Spin` | (无) | Yes | 1.0 | 0.05 |
| `JumpAir_Spin` | `JumpEnd` | `IsGrounded` | No | — | 0.1 |
| `JumpAir_Double` | `JumpEnd` | `IsGrounded` | No | — | 0.1 |
| `JumpEnd` | `Locomotion` | (无) | Yes | 1.0 | 0.1 |

### 3.4 转移细节要点

- **`JumpStart` 只能从 `Locomotion` 进入**:不要用 AnyState,防误触
- **`JumpAir` → `JumpAir_Double`**:仅 `DoubleJump` 触发,`!IsGrounded` 保证只在空中接受(代码层也校验)
- **`JumpAir_Double` → `JumpAir_Spin`**:**HasExitTime = 1.0**(强制播完 DoubleJump 动画再 Spin),Duration=0.05(快过渡)
  - 这是**关键约束**:DoubleJump 和 Spin 必须视为连接动作,不能由玩家或外部条件中断
- **`JumpAir_Double` 与 `JumpAir_Spin` 都监听 `IsGrounded` → `JumpEnd`**:覆盖"提前落地"场景(详见 §3.5)
- **`JumpAir_Spin` → `JumpEnd`**:只有 `IsGrounded` 条件,无 `DoubleJump` 二次触发(避免连按)
- **`JumpAir` 状态本身**:`IsGrounded` 是唯一退出条件(不勾 HasExitTime,避免循环到时间强制结束)
- **第三次空中按 A**:代码层在 `_jumpCount == 2` 时拒绝,不会发 `DoubleJump` trigger;状态机不需额外处理
- **Animator 组件** `Apply Root Motion = false`(本阶段不用 Root Motion)

### 3.5 提前落地处理

**问题**:玩家在 `JumpAir_Double` 或 `JumpAir_Spin` 状态中提前落地(动作链未完),如何处理?

**答案**:**直接进入 `JumpEnd`,不等待动画播完**。

- `JumpAir_Double` → `JumpEnd`(条件 `IsGrounded`,不勾 HasExitTime)
- `JumpAir_Spin` → `JumpEnd`(条件 `IsGrounded`,不勾 HasExitTime)

物理层 `IsGrounded` 由 Rigidbody / Collider 接触检测,非动画时间(由 `CharacterLocomotionMotor` 在 Update 中同步到 Animator)。
落地后 `_jumpCount = 0`,可以再次按 A 走一段跳分支。

### 3.6 完整动作链时序(参考)

```text
时间线(典型场景):
  t0:按 A 地面,trigger Jump,IsGrounded=true
     → Locomotion → JumpStart
  t0+0.1s:JumpStart 播完 → JumpAir
  t0+0.6s:按 A 空中,trigger DoubleJump,IsGrounded=false
     → JumpAir → JumpAir_Double
  t0+0.65s:DoubleJump 强制播完 → JumpAir_Spin(Duration 0.05)
  t1.0s:IsGrounded=true(落地)
     → JumpAir_Spin → JumpEnd → Locomotion
     _jumpCount 重置为 0
```

### 5.2 关键代码设计

**水平/垂直解耦**(核心):
- `CharacterMovementController` 在 Update 中持续计算 `motor.DesiredHorizontalVelocity`(camera-relative 方向 × speed),**不**受 IsGrounded 影响
- `CharacterLocomotionMotor` 在 FixedUpdate 中合并:`rb.velocity = (desired.x, rb.velocity.y, desired.z)`,**跳跃不打断水平**
- 跳跃只改 `rb.velocity.y = Sqrt(2·g·height)`,Y 方向交给 Rigidbody.UseGravity 自然下落

**地面检测**:
- `Physics.CheckSphere(rb.position + Vector3.down * 0.9f, 0.3f, groundMask, QueryTriggerInteraction.Ignore)`
- 双保险:`Physics.Raycast(rb.position + Vector3.down * 0.9f, Vector3.down, 0.2f, groundMask)`,任一命中即视为接地
- 0.1s 滞回:连续 0.1s 接地才发布 `LandedEvent`,防止抖动

**Animator 同步**:
- `CharacterLocomotionMotor.Update` 中 `animator.SetBool("IsGrounded", IsGrounded)`(每帧同步,保证转移条件及时触发)
- 跳跃接受时由 `CharacterJumpController` 调 `SetTrigger("Jump")` 或 `SetTrigger("DoubleJump")`
- 二段跳触发后,DoubleJump 动作播完由 Animator 自动切到 Spin — 代码**不**在 Spin 开始时发任何 trigger

**Sprint 兼容**:
- Sprint 仍走 `CharacterMovementController` 的水平速度通道(`_moveSpeed × sprintMultiplier`),本阶段**不**改 Sprint 任何逻辑
- 跳跃中 Sprint 状态保留(若 Sprint 进行中起跳,Sprint 继续生效;落地后 Sprint 状态由 Sprint 自身决定)

**输入接受矩阵**(`CharacterJumpController.HandleJump`):

| `_motor.IsGrounded` | `_jumpCount` | 行为 |
|---|---|---|
| true | 0 | 接受一段跳 → `Jump` trigger → `_jumpCount = 1` |
| false | 1 | 接受二段跳 → `DoubleJump` trigger → `_jumpCount = 2` |
| 其它 | — | 拒绝,不发 trigger,不发布事件 |

## 六、事件定义

| 事件 | 字段 | 发布方 | 订阅方 | 触发时机 |
|---|---|---|---|---|
| `JumpStartedEvent` | `float JumpHeight` | `CharacterJumpController` | `CharacterLocomotionMotor`(记录)、`PlayerFeedback`(可选) | 一段跳输入**被接受**时 |
| `DoubleJumpStartedEvent` | `float JumpHeight` | `CharacterJumpController` | 同上 | 二段跳输入**被接受**时 |
| `LandedEvent` | `Vector3 GroundPoint` | `CharacterLocomotionMotor` | `CharacterJumpController`(重置 `_jumpCount = 0`) | `_isGrounded` 由 false → true 上升沿(带 0.1s 滞回) |

**绝对规则**:
- 跳跃输入接受判断只在 `CharacterJumpController`(校验 `_isGrounded`、`_jumpCount`)
- Collider 不参与输入判断
- `LandedEvent` 不由 Collider 直接发布,只能由 `CharacterLocomotionMotor` 物理检测后发布
- 空中翻(`JumpAir_Spin`)期间**不**发新事件,只是 `DoubleJump` 组合动作的一部分
