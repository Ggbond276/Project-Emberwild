## 0. 本阶段头号任务：修复多怪广播 bug（🔴 最高优先级）

### 0.1 问题还原

阶段三的 `EnemyDamagedEvent` / `EnemyDiedEvent` **没有受害者引用**，而 `EnemyBrain.OnDamaged/OnDied` 是"收到就切状态、不判断是不是我"：

```text
任意一只怪被打 → 发 EnemyDamagedEvent → 场上所有 EnemyBrain 都 OnDamaged → 所有怪一起进 Hit
任意一只怪死亡 → 发 EnemyDiedEvent   → 场上所有 EnemyBrain 都 OnDied   → 所有怪一起死
```

目前靠 `SampleScene` 的 `maxEnemies = 1` 掩盖着，一旦把刷怪数调回 10 立刻暴露。

### 0.2 修复方案

给两个事件加 `Victim`（受害者）字段，`EnemyBrain` 收到后**先判断"是不是我"，不是就忽略**：

```text
EnemyDamagedEvent { Victim, Damage, CurrentHp, FromDirection }
EnemyDiedEvent    { Victim }

EnemyBrain.OnDamaged(evt) { if (evt.Victim != _entity) return; ChangeState(Hit); }
EnemyBrain.OnDied(evt)    { if (evt.Victim != _entity) return; ChangeState(Dead); }
```

> `Victim` 用阶段二引入的 `ICombatEntity`，与整个战斗抽象保持一致。

## 三、核心设计

### 3.1 决策优先级（本阶段新增的"大脑规则"）

`ChaseState.OnUpdate` 升级为**决策中枢**，按顺序命中即停：

```text
1. 残血 HpRatio < 30%                  → Hide(缩壳保命)
2. 距离 ≤ 近战距离(1.6m)                → AttackMelee
3. 距离在 3~7m 且 Roll 冷却好          → RollChase(滚过去)
4. 距离在 4~8m 且 远程冷却好           → AttackRanged(放远程)
5. 其余                                → 继续追击
```

> 受击(Hit)、死亡(Dead)仍由**事件**全局打断，不参与这里的顺序判断。

### 3.2 远程攻击：瞬发判定（不引入飞行物）

为控制复杂度，本阶段远程用**瞬发判定**：播 `ProjectileAttack` 动画的同时，在**玩家位置**做一次球形判定，命中即扣血。做法是给 `CharacterAttackHitEvent` 加一个 `TargetPosition`：

```text
近战:TargetPosition = Vector3.zero → 判定中心 = 自己 forward * OffsetZ(不变)
远程:TargetPosition = 玩家位置      → 判定中心 = 该点(OverlapSphere)
```

> 弹道飞行物是后续优化，本阶段先用瞬发保证闭环。

### 3.3 滚动冲刺：直线高速移动

`RollChase` 期间**不走 A* 绕路**，而是朝玩家方向**直线**高速冲刺（滚动本来就是直线）。给 `CustomNavAgent` 加一个 `SetDirectVelocity(dir, speed)`，与 `SetDestination`（寻路）并存、互不干扰。

### 3.4 缩壳防御：Bool 状态 + 减伤

`Hide` 是持续状态（不是一次性动作），沿用"持续状态用 Bool"的约定：

```text
OnEnter: SetHidden(true) + Attribute.IsHidden = true   → 播 Hide + 减伤 50%
OnUpdate: 超时(3s) → 出壳回 Chase
OnExit:  SetHidden(false) + Attribute.IsHidden = false
```

减伤放在 `CombatAttribute.TakeDamage` 开头：`if (IsHidden) damage *= 0.5f`。

### 3.5 血量比例 HpRatio 的维护

`EnemyBrain.OnDamaged` 里顺手更新黑板：`BB.HpRatio = evt.CurrentHp / Entity.MaxHp`，供 `ChaseState` 判断是否缩壳。
