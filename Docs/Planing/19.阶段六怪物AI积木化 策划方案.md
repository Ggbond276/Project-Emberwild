# 19. 阶段六怪物 AI 积木化 策划方案

> 承接：`18.怪物AI积木化架构设计.md`（v2 已确认）
> **目标**：落地「搭积木」框架，让使用者**仅凭一份 README 就能独立新建一只怪物 AI**。

---

## 一、设计目标

1. **搭积木式搭建**：新建怪物 = 挂通用组件 + 实现专属 Animator + 建一份专属配置，核心代码零改动。
2. **结构复用、数据独立**：所有怪共用一份配置结构（`EnemyAIConfig` 类）与运行时代码，但每只怪的参数值是独立资产，改 A 不影响 B。
3. **动画解耦**：`EnemyAnimator` 重命名 `ShellAnimator`，抽象统一接口 `IEnemyAnimator`，各怪实现自己的 Animator。
4. **行为可配置**：决策树由 `EnemyAIConfig.decisionTree` 描述，换怪换行为只改配置、不改代码。

---

## 二、模块划分（三类积木）

| 积木 | 模块 | 复用 or 实现 |
| -- | -- | -- |
| **通用积木** | `EnemyBrain`（决策驱动）· `EnemyPerception`（感知）· `CustomNavAgent`（移动）· `EnemyCombat`（攻击）· `EnemyEntity`（数据）· 行为树框架 · 状态机框架 · 黑板 | 复用，不改 |
| **特殊积木** | Animator（`ShellAnimator`/`WolfAnimator`，实现 `IEnemyAnimator`）· 特殊状态（可选，实现 `IEnemyState`） | 每怪实现 |
| **配置** | `EnemyAIConfig` 类（统一结构）+ `ShellAI.asset`/`WolfAI.asset`（每怪实例） | 结构复用，数据独立 |

### 依赖关系（一帧数据流）

```text
Perception(感知) ──写──► 黑板 ◄──写── EventBus(受击/死亡事件)
                              │读
EnemyBrain ──行为树决策──► ChangeState ──► 状态机(OnEnter/OnUpdate/OnExit)
                              │语义指令
              NavAgent(移动) · Combat(攻击) · IEnemyAnimator(动画)
```

## 三、行为逻辑

### 3.1 决策：行为树（可配置）

`EnemyAIConfig.decisionTree` 是一棵 `Selector` 树，自上而下 = 优先级从高到低。每分支 = `Sequence(条件…, 动作)`。

Shell 的 8 分支（示例）：

| 优先级 | 条件 | 动作 |
| -- | -- | -- |
| 1 | IsDead | Dead |
| 2 | RecentlyHit(0.4) | Hit |
| 3 | NotHidden + HasTarget + HpBelow(0.3) | Hide |
| 4 | HasTarget + InRange(0, 1.6) | AttackMelee |
| 5 | HasTarget + InRange(3, 7) + CooldownRollReady(4) | RollChase |
| 6 | HasTarget + InRange(4, 8) + CooldownAttackReady(2) | AttackRanged |
| 7 | HasTarget | Chase |
| 8 | Always | Idle |

### 3.2 执行：状态机（可复用）

`IEnemyState` 三生命周期（OnEnter/OnUpdate/OnExit）不变；`EnemyStateFactory` 作为状态零件库，新状态 = 实现接口 + `Register` 一行。

### 3.3 动画：接口映射

状态类只调 `IEnemyAnimator` 的语义方法（`PlayAttack`/`PlayRangedAttack`/`SetRoll`/…），由各 Animator 翻译成自己的 Animator 参数。

## 四、数据配置方式

### 4.1 统一配置结构 `EnemyAIConfig`（一份类定义，所有怪共用）

字段分五组：**感知 / 移动 / 战斗 / 特殊能力 / 决策树**（详见手册步骤 4）。

### 4.2 每怪一份实例（数据独立）

```text
ShellAI.asset → runSpeed=3,  viewRange=5,  决策树含缩壳分支
WolfAI.asset  → runSpeed=6,  viewRange=10, 决策树无缩壳、含嚎叫分支
```

### 4.3 运行时代码读配置

`EnemyBrain.Awake` 读自己引用的 `_config`，把感知/移动参数注入组件，用 `BTBuilder` 从 `decisionTree` 建树，用 `EnemyStateFactory` 建状态。
