# 5. 小螃蟹 Animator 搭建操作手册

> 配套文档：`4.ARPG 怪物AI与状态机系统策划方案.md`  
> 目标文件：`Assets/Art/UnityPackage/Monsters/Monsters Ultimate Pack 02 Cute Series/Shell Cute Series/FBX/Shell.controller`  
> 本文是**纯操作步骤**，照着点即可，不需要写代码。

---

## 步骤 0：开工准备

1. Unity 里双击 `Shell.controller` 打开 **Animator 窗口**（或 `Window → Animation → Animator`）。
2. 展开左下 **Parameters 面板** 与右下 **Layers 面板**。
3. **先备份**：Project 窗口选中 `Shell.controller`，按 `Ctrl+D` 复制一份留底。

---

## 步骤 1：动画取舍（20 个里只用 11 个）

### 要用的（11 个）

| clip 名                  | 归属         | 用途                |
| ----------------------- | ---------- | ----------------- |
| `Idle`                  | Locomotion | Blend Tree 阈值 0   |
| `Walk Forward In Place` | Locomotion | Blend Tree 阈值 0.5 |
| `Run Forward In Place`  | Locomotion | Blend Tree 阈值 1.0 |
| `Bite Attack`           | Action     | 近战攻击              |
| `Projectile Attack`     | Action     | 远程攻击              |
| `Cast Spell`            | Action     | 施法                |
| `Roll Forward In Place` | Action     | 滚动冲刺              |
| `Hide`                  | Reaction   | 缩壳（循环）            |
| `Hide to Idle`          | Reaction   | 出壳（单次）            |
| `Take Damage`           | Reaction   | 受击                |
| `Die`                   | Reaction   | 死亡                |

### 不用的（9 个）与理由

| clip 名                                                                                                          | 理由                                                                              |
| --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `Walk Left In Place` / `Walk Right In Place`                                                                    | 怪物追击是「朝目标走」，不需要横向移动。以后做环绕走位再加                                                   |
| `Turn Left` / `Turn Right`                                                                                      | **会和寻路打架**：`CustomNavAgent` 已用 `Quaternion.Slerp` 做连续转向，再叠一个原地转身动画会抽搐           |
| `Walk Forward W Root` / `Walk Left W Root` / `Walk Right W Root` / `Run Forward W Root` / `Roll Forward W Root` | **W Root = 带根位移（Root Motion）**。本阶段统一用 `In Place` + 代码位移（与玩家侧一致），5 个 W Root 全部不用 |

### ⚠️ 关于缩壳的重要说明

包里**没有** `Idle to Hide` 这个动画（已逐个验证 FBX 内部名字）。  
原 controller 里那个 "Idle to Hide" 状态实际复用的还是 `Hide to Idle` 这个 clip。

**正确做法**：

- 进壳 → 直接切到 `Hide`（该 clip 本身包含缩壳过程并循环）
- 出壳 → 播 `Hide to Idle`

不需要额外的进壳动画。

---

## 步骤 2：清空旧状态

原 controller 是资源包作者的**演示用**结构（状态名有 `Idle 5`、`Idle 6`、`Walk Forward In Place 0` 这类重复命名），全部清掉。

1. 点 Base Layer 空白画布 → `Ctrl+A` 全选。
2. `Delete` 删除。**不要删掉 Base Layer 本身**（Layers 面板里那一层要保留）。
3. 画布上应只剩 **Entry / Any State / Exit** 三个内置节点。

---

## 步骤 3：创建 8 个参数

在 Animator 窗口左下 **Parameters 面板**，点 `+` 逐个添加：

| 参数名                | 类型      | 作用                          |
| ------------------ | ------- | --------------------------- |
| `Speed`            | Float   | 0 = Idle，0.5 = Walk，1 = Run |
| `IsDead`           | Bool    | 死亡开关（true 后永久锁死）            |
| `IsHidden`         | Bool    | 缩壳开关                        |
| `Attack`           | Trigger | 近战攻击                        |
| `ProjectileAttack` | Trigger | 远程攻击                        |
| `CastSpell`        | Trigger | 施法                          |
| `Roll`             | Trigger | 滚动冲刺                        |
| `TakeDamage`       | Trigger | 受击（打断当前动作）                  |

> **大小写必须完全一致**。`Animator.StringToHash("Speed")` 区分大小写，错一个字母就是"动画不动"。



---

## 步骤 4：搭骨架（3 个区域 + 2 个独立状态）

```text
Base Layer
├── Locomotion                 1D Blend Tree（Idle → Walk → Run）★ 默认入口
├── [Action]  子状态机
│   ├── BiteAttack
│   ├── ProjectileAttack
│   ├── CastSpell
│   └── Roll
├── [Reaction]  子状态机
│   ├── Hide
│   └── Unhide
├── TakeDamage                 放顶层（Any State 打断用）
└── Dead                       放顶层 · 无出口
```

**为什么 TakeDamage / Dead 不放进子状态机？**  
`Any State`（任意状态打断）指向**顶层状态**最稳定。Unity 对 "Any State → 子状态机内部状态" 的支持在不同版本表现不一致，放顶层可避免踩坑。

**操作顺序**：

1. 右键空白 → `Create State → Empty`，命名 `Locomotion`。
2. 右键空白 → `Create Sub-State Machine`，命名 `Action`。双击进去，建 4 个 Empty 状态：`BiteAttack` / `ProjectileAttack` / `CastSpell` / `Roll`。
3. 再建子状态机 `Reaction`，双击进去建 2 个：`Hide` / `Unhide`。
4. 回到 Base Layer 顶层，建 2 个：`TakeDamage` / `Dead`。

---

## 步骤 5：给状态挂 clip

选中状态 → 右侧 Inspector 的 `Motion` 字段拖入对应 clip。

| 状态                 | clip                    | Loop Time      |
| ------------------ | ----------------------- | -------------- |
| `BiteAttack`       | `Bite Attack`           | 不勾             |
| `ProjectileAttack` | `Projectile Attack`     | 不勾             |
| `CastSpell`        | `Cast Spell`            | 不勾             |
| `Roll`             | `Roll Forward In Place` | 不勾             |
| `Hide`             | `Hide`                  | **勾**（缩壳后持续保持） |
| `Unhide`           | `Hide to Idle`          | 不勾             |
| `TakeDamage`       | `Take Damage`           | 不勾             |
| `Dead`             | `Die`                   | 不勾             |

> **口诀**：能一直保持的状态勾（Idle / Walk / Run / Hide），一次性的动作不勾（攻击 / 受击 / 死亡 / 出壳）。  
> 找不到 Loop Time：选中 clip 文件 → Inspector 展开 `Animation` 页签 → 勾 `Loop Time`。

---

## 步骤 6：配置 Locomotion 的 Blend Tree

1. 双击 `Locomotion` 状态，进入 Blend Tree 编辑界面。
2. Inspector 里 `Blend Type` = **1D**，`Parameter` = **Speed**。
3. `+ → Add Motion Field` 三次，按下表填：

| Threshold | Motion                  |
| --------- | ----------------------- |
| `0`       | `Idle`                  |
| `0.5`     | `Walk Forward In Place` |
| `1`       | `Run Forward In Place`  |

> **为什么 Idle 也放进 Blend Tree？** 这样 `Speed` 从 0 渐变到 1 时 Idle→Walk→Run 自动平滑过渡，不需要为 Idle 单独建状态和连线。代码侧只需一句：  
> `animator.SetFloat("Speed", agent.VelocityMagnitude / runSpeed);`

---

## 步骤 7：连线（14 条过渡）

连线方法：**右键起点状态 → Make Transition → 点终点状态**。连好后点中箭头，在 Inspector 里按下表设置。

> ⚠️ **子状态机的连线分两层，别搞混**（详见 `5.1.子状态机连线详解.md`）：
> - **进入**：在外层画。拖线到六边形上松手时会弹菜单，选**具体状态**（点名进入）或**整个状态机**（走 Entry）。
> - **盒子里面的线**：**双击**六边形进去画。
> - **离开**：必须先在内部连到 `Exit`，再由**整个六边形**连回外层。**不能从内部状态直接连到外层状态。**

### A. 从 Locomotion 出发

| 起点         | 终点               | 条件                           | Has Exit Time | Duration |
| ---------- | ---------------- | ---------------------------- | ------------- | -------- |
| Locomotion | BiteAttack       | `Attack` (Trigger)           | 不勾            | 0.1      |
| Locomotion | ProjectileAttack | `ProjectileAttack` (Trigger) | 不勾            | 0.1      |
| Locomotion | CastSpell        | `CastSpell` (Trigger)        | 不勾            | 0.1      |
| Locomotion | Roll             | `Roll` (Trigger)             | 不勾            | 0.1      |
| Locomotion | Hide             | `IsHidden` = true            | 不勾            | 0.15     |

### B. 从动作回到 Locomotion（⚠️ 必须分两层连）

**第 1 步：双击进入 `[Action]` / `[Reaction]` 子状态机，在内层连到 `Exit`**

| 起点               | 终点   | 条件  | Has Exit Time | Exit Time |
| ---------------- | ---- | --- | ------------- | --------- |
| BiteAttack       | Exit | 无条件 | 勾             | 0.9       |
| ProjectileAttack | Exit | 无条件 | 勾             | 0.9       |
| CastSpell        | Exit | 无条件 | 勾             | 0.9       |
| Roll             | Exit | 无条件 | 勾             | 0.9       |
| Unhide           | Exit | 无条件 | 勾             | 0.9       |

**第 2 步：回到外层，由整个子状态机连回 `Locomotion`**

| 起点                | 终点         | 条件  | Has Exit Time | Duration |
| ----------------- | ---------- | --- | ------------- | -------- |
| `[Action]` 六边形    | Locomotion | 无条件 | 勾             | 0.15     |
| `[Reaction]` 六边形  | Locomotion | 无条件 | 勾             | 0.15     |
| TakeDamage        | Locomotion | 无条件 | 勾             | 0.1      |

> `TakeDamage` 是**顶层状态**（不在子状态机里），所以它可以直连 `Locomotion`，不需要走 Exit。

### C. 缩壳进出

| 起点   | 终点     | 条件                 | Has Exit Time | Duration |
| ---- | ------ | ------------------ | ------------- | -------- |
| Hide | Unhide | `IsHidden` = false | 不勾            | 0.15     |

> ⚠️ 出壳**不要用 `Unhide` 触发器**。缩壳/出壳是同一件事的两面，统一由 `IsHidden` 这一个 Bool 表达：`true` = 待在壳里，`false` = 出来。用两个参数会出现"两个旋钮必须永远同步"的隐患，详见 `5.2.缩壳状态机Hide-Unhide参数方案分析.md`。

### D. 全局打断（Any State 出发）

| 起点            | 终点         | 条件                     | Has Exit Time | Duration |
| ------------- | ---------- | ---------------------- | ------------- | -------- |
| **Any State** | Dead       | `IsDead` = true        | 不勾            | 0.1      |
| **Any State** | TakeDamage | `TakeDamage` (Trigger) | 不勾            | 0.05     |

### 🔴 Any State 的三个必设项

1. `Can Transition To Self` **必须取消勾选** —— 否则受击动画不停打断自己，表现为**抽搐/抖动**。
2. `Has Exit Time` **必须取消勾选** —— 否则要等当前动画播完才切，失去"打断"意义。
3. **Any State → Dead 要排在 Any State → TakeDamage 上面**（在 Any State 的过渡列表里拖动排序），保证"死了"优先级高于"受击"。

---

## 步骤 8：默认状态 + 自检

1. 右键 `Locomotion` → `Set as Layer Default State`（变橙色）。
2. 确认 `Entry` 只有一条箭头指向 Locomotion。
3. `Ctrl+S` 保存。

### 自检清单

- [ ] Parameters 里有 **8 个**参数，拼写与大小写完全一致
- [ ] 画布上有 **Locomotion / Action / Reaction / TakeDamage / Dead** 五个块
- [ ] Locomotion 里有 **3 个 Motion**，Threshold = 0 / 0.5 / 1
- [ ] 一次性动作的 **Loop Time 都没勾**
- [ ] `Hide` 的 **Loop Time 勾了**
- [ ] Any State 的 2 条过渡都**没勾 Can Transition To Self**
- [ ] `Dead` **没有任何出去的箭头**
- [ ] `Locomotion` 是默认状态（橙色）

> **最快验证法**：运行游戏，Inspector 选中螃蟹的 Animator，手动拨动 `Speed` 滑块（0 → 1），看是否从站立平滑走到奔跑；再手动打勾 `IsHidden` 看是否缩壳。**不写一行代码就能验证 Animator 搭得对不对。**

## 附录：代码与参数的对应关系

```text
EnemyAnimator 方法              →  Animator 参数              →  实际播放
─────────────────────────────────────────────────────────────────────────
SetMoveSpeed(v)                 →  Speed = v                 →  Idle/Walk/Run 混合
PlayBiteAttack()                →  Attack (Trigger)          →  Bite Attack
PlayProjectileAttack()          →  ProjectileAttack (Trigger)→  Projectile Attack
PlayCastSpell()                 →  CastSpell (Trigger)       →  Cast Spell
PlayRoll()                      →  Roll (Trigger)            →  Roll Forward In Place
EnterHide()                     →  IsHidden = true           →  Hide（循环）
ExitHide()                      →  IsHidden = false   →  Hide to Idle
PlayTakeDamage()                →  TakeDamage (Trigger)      →  Take Damage
PlayDie()                       →  IsDead = true             →  Die
```

> **分工原则**：代码只管"**说什么**"（语义方法），Animator 只管"**长什么样**"。  
> 永远写 `animator.PlayBiteAttack()`，而不是 `animator.SetTrigger("Attack")`——这样以后改参数名，只需改 `EnemyAnimator` 一个地方。
