## 步骤 1：修复缩壳死循环（🔴 最影响行为，先做）

**问题**：残血怪缩壳 → 出壳回 Chase → 行为树又判残血 → 又缩壳，无限循环。

改 3 处：

### 1.1 黑板加一次性标志

**文件**：`Assets/Scripts/AI/Enemy/EnemyBlackboard.cs`

在 `LastHitTime` 后面加：

```csharp
        /// <summary>
        /// 本次战斗是否已缩壳过(一次性标志,避免出壳后反复缩壳)
        /// </summary>
        public bool HasHidden;
```

### 1.2 Hide 条件加 `!HasHidden`

**文件**：`Assets/Scripts/AI/Enemy/EnemyBrain.cs`

在 `BuildTree()` 里，把第 3 条"缩壳"的条件改掉：

```csharp
                // 3. 缩壳(残血,仅一次)
                new Sequence(
                    new Condition(b => !b.BB.HasHidden && b.BB.CanSeeTarget && b.BB.HpRatio < b.HideHpThreshold),
                    new ActionNode(EnemyStateType.Hide)
                ),
```

### 1.3 进入 Hide 时置标志

**文件**：`Assets/Scripts/AI/Enemy/State/HideState.cs`

`OnEnter` 里加一行：

```csharp
        public void OnEnter(EnemyBrain brain)
        {
            _hideEndTime = Time.time + brain.HideDuration;
            brain.BB.HasHidden = true;   // ← 新增:缩过一次壳就不再缩

            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);
            brain.Animator.SetHidden(true);
            brain.Entity.Attribute.IsHidden = true;
        }
```

**✅ 验证**：把螃蟹打残血 → 它缩一次壳 → 出壳后**不再反复缩**，转而追你/待机。

## 步骤 2：修复 `EnemyDiedEvent` 孤儿事件（🔴 架构健壮性）

**问题**：`CombatAttribute` 还在发 `EnemyDiedEvent`，但 `EnemyBrain` 已取消订阅 → 事件成死代码。

**方案**：恢复订阅，`OnDied` 做"0 帧死亡处理"（立即切 Dead）。

**文件**：`Assets/Scripts/AI/Enemy/EnemyBrain.cs`

改 2 处：

**① `OnEnable` / `OnDisable` 恢复订阅**：

```csharp
        private void OnEnable()
        {
            EventBus.Subscribe<EnemyDamagedEvent>(OnDamaged);
            EventBus.Subscribe<EnemyDiedEvent>(OnDied);
        }

        private void OnDisable()
        {
            EventBus.Unsubscribe<EnemyDamagedEvent>(OnDamaged);
            EventBus.Unsubscribe<EnemyDiedEvent>(OnDied);
        }
```

**② 加回 `OnDied` 方法**（放在 `OnDamaged` 后面）：

```csharp
        /// <summary>
        /// 死亡:0 帧立即切 Dead(最高优先级、不可逆)。
        /// 行为树里的 IsDead 条件保留作兜底(万一事件未触发)。
        /// </summary>
        private void OnDied(EnemyDiedEvent evt)
        {
            if (!_initialized) return;
            if (evt.Victim != (ICombatEntity)_entity) return;
            ChangeState(EnemyStateType.Dead);
        }
```

**✅ 验证**：打死螃蟹 → `Shell → Dead` **立即**打印（不再等行为树下一帧）。`EnemyDiedEvent` 从此有订阅者，将来掉落/计分可直接订阅。

## 步骤 3：死亡后短路（轻，性能与语义）

**问题**：进入 `Dead` 后，`Update` 仍每帧感知 + 决策，空转。

**文件**：`Assets/Scripts/AI/Enemy/EnemyBrain.cs`

`Update` 开头加一行短路：

```csharp
        private void Update()
        {
            if (!_initialized) return;

            // 死亡后短路:不再感知、不再决策、不再执行
            if (_currentStateType == EnemyStateType.Dead) return;

            _perception.Tick(BB);          // 1. 感知写黑板
            _root.Evaluate(this);          // 2. 行为树决策
            _currentState?.OnUpdate(this); // 3. 状态执行
        }
```

**✅ 验证**：打死螃蟹后，Console 不再出现任何新的状态流转/感知日志，尸体彻底静止。

**问题**：`_defaultState` 字段 + `Start` 里的 `ChangeState` 已被行为树覆盖，留着误导。

**文件**：`Assets/Scripts/AI/Enemy/EnemyBrain.cs`

**① 删除字段**：


**② `Start` 里删除 `ChangeState` 调用**：

