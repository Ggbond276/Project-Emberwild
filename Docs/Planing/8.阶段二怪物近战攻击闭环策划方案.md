# 8. 阶段二怪物近战攻击闭环 策划方案

> 承接：`4.ARPG 怪物AI与状态机系统策划方案.md`（阶段二）、`7.阶段一收尾与验收手册（复检修正版）`
> **一句话目标**：让阶段一"只会追"的螃蟹，变成**追到面前会咬人、玩家会掉血**的敌人。

## 一、目标与范围

### 1.1 目标

打通「**怪物 → 玩家**」的伤害闭环，端到端验证：

```text
螃蟹发现玩家 → 追击 → 进入近战距离 → 播放 Bite Attack → 攻击判定命中玩家 → 玩家扣血
```

### 1.2 范围内（本阶段做）

| 项 | 内容 |
| -- | -- |
| 战斗抽象层 | 引入阵营 `FactionType` + 统一实体契约 `ICombatEntity` |
| 阵营修复 | 改造 `CombatDetector`，按攻击者阵营选目标层（修"怪物打不动玩家"） |
| 攻击执行 | 新写 `EnemyCombat`（AI 驱动攻击 → 发攻击事件） |
| 攻击状态 | 新写 `AttackMeleeState` + 枚举加 `AttackMelee` + `EnemyBrain` 注册 + `ChaseState` 加近战判定 |
| 数据表 | `AttackDefine.txt` 新增 `ComboGroup: "Shell"` 近战段 |
| 配置 | `Shell.prefab` 挂 `EnemyCombat` 组件 |

### 1.3 范围外（本阶段严格不做）

```text
├─ 玩家受击动画 / 死亡（阶段三：Hit/Dead + 事件反馈链）

├─ 攻击连段（本阶段只有单段咬击，连段后续再加）

├─ 玩家侧输入与移动逻辑（不动 Character* 的行为逻辑）
└─ 行为树（阶段五）
```

## 三、核心设计

### 3.1 阵营抽象（本阶段最关键的一处）

**问题**：`CombatDetector` 构造函数里写死 `_targetLayerMask = LayerMask.GetMask("Monster")`，无论谁攻击都只扫 Monster 层 → 怪物攻击玩家时扫不到玩家。

**方案**：引入阵营，让攻击者自己声明"我是谁"，检测器据此决定"打谁"：

```text
FactionType.Player  攻击  → 目标层 Monster
FactionType.Monster 攻击  → 目标层 Player
```

**统一实体契约**：新增 `ICombatEntity`，让 `CharacterEntity` 与 `EnemyEntity` 都实现它，`CombatDetector` 只依赖接口、不再区分具体类型：

```csharp
public interface ICombatEntity
{
    string        SubType;    // 查连招表的钥匙(如 "Shell")
    FactionType   Faction;    // 阵营
    Transform     Transform;  // 位置/朝向
    CombatAttribute Attribute; // 攻击者的属性面板
}
```

> 这样做的价值：以后再加第三种怪（如 Snake），只要它的实体实现 `ICombatEntity`，伤害管线**一行不用改**。这就是"面向接口"。

### 3.2 EnemyCombat（怪物攻击执行层）

照抄 `CharacterCombat` 的思想，但**由 AI 驱动、无输入、单段攻击**：

```text
AttackMeleeState.OnEnter → EnemyCombat.DoAttack()
    ├─ 播 Bite Attack 动画(EnemyAnimator.PlayBiteAttack)
    ├─ 发布 CharacterAttackHitEvent(_entity, 0)
    └─ 记录硬直窗口(IsAttacking)
```

`IsAttacking` 是攻击的"硬直锁"：攻击动画期间不能再攻、状态不能提前退出，保证"一刀一刀"干净利落。

### 3.3 AttackMelee 状态流转

```text
Chase（距离 ≤ MeleeRange）
    → AttackMelee（OnEnter 刹车 + 咬一口）
    → 硬直结束（IsAttacking == false）
        → 还看得到目标 → Chase
        → 看不到了     → Idle
```

`MeleeRange`（默认 1.6m）与判定框（`OffsetZ`/`Param1`/`Param2`）配合，保证咬得到。

### 3.4 数据流（一帧内）

```text
EnemyPerception.Tick → 黑板 DistanceToTarget / CanSeeTarget
    ↓
ChaseState.OnUpdate：距离 ≤ MeleeRange？ → ChangeState(AttackMelee)
    ↓
AttackMeleeState.OnEnter → EnemyCombat.DoAttack()
    ↓ 发布 CharacterAttackHitEvent(EnemyEntity, combo=0)
CombatDetector：查 ComboGroupDict["Shell"][0] → 按 Faction.Monster 选 Player 层 → Overlap 判定
    ↓ 命中
玩家 CombatAttribute.TakeDamage(damage) → 掉血(日志可见)
```

## 七、潜在风险与应对措施

| # | 风险 | 影响 | 应对 |
| -- | -- | -- | -- |
| 1 | 阵营改造误伤"玩家打怪" | 玩家攻击失效 | 2.1 单独回归：改完先测玩家攻击仍掉血 |
| 2 | 事件类型泛化导致编译错误扩散 | 一堆文件报错 | 用接口 + 隐式转型；`CharacterCombat` 无需改（`CharacterEntity` 自动转 `ICombatEntity`） |
| 3 | 判定框参数不对，打不到或贴脸 | 咬不到人 | 用 `Gizmos` 可视化判定框 + Inspector 可调 `OffsetZ/Param1/Param2` |
| 4 | `SubType` 拼写错误（历史 MC19 `SowrdAndShield` 坑） | 查表失败 | `CharacterDefine` 的 `SubType` 与 `AttackDefine` 的 `ComboGroup` 严格一致 `"Shell"` |
| 5 | 攻击频率失控（每帧都咬） | 动画抽搐、伤害爆炸 | `EnemyCombat.IsAttacking` 硬直锁 + `AttackMeleeState` 只在硬直结束后退出 |
| 6 | 玩家被咬无反馈，感觉"没被打到" | 体验差 | 属阶段三范畴；阶段二验收只看 `CombatAttribute` 掉血日志，阶段三再补受击动画 |
| 7 | `EnemyCombat` 漏挂到 prefab | 攻击状态空引用 | `EnemyBrain` 的 `Awake` 自动 `GetComponent` + Start 判空日志 |

## 八、验收标准

### 8.1 阶段二验收（逐条勾选）

1. [ ] 玩家走进螃蟹近战距离内 → Console 打印 `Shell → AttackMelee`
2. [ ] 螃蟹播放 `Bite Attack` 动画，追击停止（刹车）
3. [ ] 攻击判定命中 → 玩家 `CombatAttribute` 掉血（Console 打印 `MC19 受到 X 伤害, 剩余 HP: Y`）
4. [ ] 攻击硬直结束 → 回 `Chase`，玩家若在视野内继续追击
5. [ ] 玩家拉开距离 → 螃蟹回 `Chase`，不再无脑贴脸咬
6. [ ] **回归**：玩家攻击仍能打到螃蟹（`Shell 受到 X 伤害`）

### 8.2 全阶段完成后（阶段四）的远期验收（存档）

> 螃蟹能追、能近战、能远程、残血缩壳、被打断、会死；换怪只换动画、决策零改动。
