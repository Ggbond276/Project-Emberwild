## 1. 可选清理（不强制，做了更干净）

### 1.1 删除游离的 controller 副本

`Assets/Art/Animators/Shell.controller`（含同名 `.meta`）是重建过程中的旧副本（9 参数含 Unhide），prefab 未引用它。确认 Project 面板里无任何引用后删除，避免以后拖错。

### 1.2 删除旧 `EnemyAI.cs`

`Assets/Scripts/AI/EnemyAI.cs`（含 `.meta`）已被 `EnemyBrain` 取代，`Shell.prefab` 上也没挂它，可删。

### 1.3 删除 `ChaseState` 冗余死代码

**文件**：`Assets/Scripts/AI/Enemy/State/ChaseState.cs`

删除 `OnUpdate` 开头这段从 Idle 复制粘贴残留的块：

```csharp
        public void OnUpdate(EnemyBrain brain)
        {
            var bb = brain.BB;

            if (brain.BB.CanSeeTarget)          // ← 删这 4 行
            {
                brain.ChangeState(EnemyStateType.Chase);
            }

            if (bb.Target == null || !bb.CanSeeTarget)
            {
                brain.ChangeState(EnemyStateType.Idle);
                return;
            }

            brain.Agent.SetDestination(bb.Target.position);
            brain.Animator.SetMoveSpeed(brain.NormalizedSpeed);
        }
```

改为：

```csharp
        public void OnUpdate(EnemyBrain brain)
        {
            var bb = brain.BB;

            if (bb.Target == null || !bb.CanSeeTarget)
            {
                brain.ChangeState(EnemyStateType.Idle);
                return;
            }

            brain.Agent.SetDestination(bb.Target.position);
            brain.Animator.SetMoveSpeed(brain.NormalizedSpeed);
        }
```

### 1.4 修正 `EnemyAnimator` 方法名拼写

**文件**：`Assets/Scripts/AI/Enemy/EnemyAnimator.cs`

把 `PlayerProjectileAttack` 改为 `PlayProjectileAttack`（阶段四 `AttackRanged` 状态会调用它）：

```csharp
        public void PlayProjectileAttack()      // ← 原名 PlayerProjectileAttack
        {
            if (_animator == null) return;
            _animator.ResetTrigger(_projectileAttackHash);
            _animator.SetTrigger(_projectileAttackHash);
        }
```

## 2. 端到端运行验收（阶段一验收标准）

1. 打开 `SampleScene.unity`，确认有 `Spawner` + `TestRunner`。
2. 点 Play 运行。
3. 控制玩家角色**走进任意一只螃蟹 10 米内**。

**逐条勾选：**

- [ ] Console 打印 `Shell → Chase`
- [ ] 螃蟹转身朝玩家走来，速度动画在 Walk → Run 平滑过渡
- [ ] Scene 视图里螃蟹脚下画出黑色 A* 路径
- [ ] 玩家走远（超 13 米）→ Console 打印 `Shell → Idle`，螃蟹停下
- [ ] 玩家再靠近 → 重新 Chase

**如果动画不动**：运行中打开 Animator 窗口，手动拨 `Speed` 滑块 0→1，看 Idle→Walk→Run。能拨动但代码驱动无效 → 回查 prefab 的 Animator Controller 是否指向含 Blend Tree 的那个；拨了也没变化 → 回看 `5.小螃蟹Animator搭建操作手册.md`。

## 3. 报错对照表

| 现象 | 原因 | 修法 |
| -- | -- | -- |
| 场景刷出来灰色胶囊 | Spawner 仍指向 Enemy.prefab | 确认 `enemyPrefab` = Shell（已确认正确） |
| 螃蟹会追但动画不变 | Animator Controller 指向无 Blend Tree 的版本 | 确认 prefab 指向美术包内 8 参数重建版 |
| `NullReferenceException` 在 `CustomNavAgent.Awake` | Shell 缺 Rigidbody | 检查 prefab（已确认有） |
| 螃蟹一直 Idle 不 Chase | 玩家不在 Player 层 / 感知没勾 Player | 确认玩家 Layer=Player，感知 Target Layer 勾 Player |
| 螃蟹追两步抽搐 | `Apply Root Motion` 勾了 | 取消勾选（已确认是 0） |
| 螃蟹原地溜冰 | `Run Speed` 与 `moveSpeed` 不一致 | 两处都设 4 |
| 视野边缘 Idle↔Chase 抖动 | `Sight Range` == `Lose Target Range` | 设 10 / 13 |
| 螃蟹撞墙不动 | 寻路网格没初始化 | 检查 TestRunner `_obstacleMask` 勾 Obstacle |
