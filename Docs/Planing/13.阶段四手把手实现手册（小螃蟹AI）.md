## 步骤 1：🔴 修复多怪广播（最高优先级，独立闭环）

**为什么？** 现在 `EnemyDamagedEvent`/`EnemyDiedEvent` 没有"受害者"，所有 `EnemyBrain` 收到就切状态 → 一只挨打全员受击、一只死亡全员暴毙。本步骤给事件加 `Victim`，让每只怪只认领"自己的"事件。

### 1.1 改造 `EnemyDamagedEvent.cs`

**文件**：`Assets/Scripts/Core/Events/EnemyDamagedEvent.cs`

**整体替换**为：

```csharp
using Emberwild.Combat;
using UnityEngine;

namespace Emberwild.Core.Events
{
    /// <summary>怪物受击事件。携带受害者,供多怪场景各自认领。</summary>
    public readonly struct EnemyDamagedEvent : IEvent
    {
        /// <summary>受害者(被打的那只怪)。</summary>
        public readonly ICombatEntity Victim;
        /// <summary>实际扣血量。</summary>
        public readonly float Damage;
        /// <summary>受到伤害后剩余的HP。</summary>
        public readonly float CurrentHp;
        /// <summary>受到攻击的方向。</summary>
        public readonly Vector3 FromDirection;

        public EnemyDamagedEvent(ICombatEntity victim, float damage, float currentHp, Vector3 fromDirection)
        {
            Victim = victim;
            Damage = damage;
            CurrentHp = currentHp;
            FromDirection = fromDirection;
        }
    }
}
```

### 1.4 改造 `EnemyBrain.cs` 判断"是不是我"

**文件**：`Assets/Scripts/AI/Enemy/EnemyBrain.cs`

把 `OnDamaged` / `OnDied` 改成（注意：顺带更新 `HpRatio`，步骤 4 缩壳要用）：

```csharp
        /// <summary>受击:只有"自己"挨打才切 Hit。</summary>
        private void OnDamaged(EnemyDamagedEvent evt)
        {
            if (!_initialized) return;
            if (evt.Victim != _entity) return;      // ← 不是自己,忽略

            // 顺带更新血量比例(缩壳判断用)
            BB.HpRatio = Entity != null ? evt.CurrentHp / Entity.MaxHp : 1f;

            ChangeState(EnemyStateType.Hit);
        }

        /// <summary>死亡:只有"自己"死亡才切 Dead。</summary>
        private void OnDied(EnemyDiedEvent evt)
        {
            if (!_initialized) return;
            if (evt.Victim != _entity) return;      // ← 不是自己,忽略

            ChangeState(EnemyStateType.Dead);
        }
```

> 关键：`evt.Victim != _entity` 是引用比较。发事件时的 `Victim`（`CombatAttribute` 里 `GetComponent<ICombatEntity>()` 拿到的）和 `EnemyBrain` 的 `_entity`（`GetComponent<EnemyEntity>()` 拿到的）指向**同一个组件实例**，所以"自己挨打"时相等、"别人挨打"时不等。

**✅ 预期结果**：编译 0 报错。

**🧪 验证（必做）**：把场景 `Spawner` 的 `Max Enemies` 调回 **10**，Play。打一只螃蟹——**只有被它挨打时它才 `Shell → Hit`**，其他螃蟹该追追、该站站。打死一只——**只有它 `Shell → Dead`**，其余不受影响。

**❓ 排查**：若"打一只全体还是动"，检查 1.4 的 `if (evt.Victim != _entity) return;` 是否漏写；若"打哪只都没反应"，说明 `Victim` 引用与 `_entity` 不匹配，检查 1.3 是否把 `_entity` 传进了事件。

## 步骤 2：滚动冲刺 `RollChase`

**为什么？** 让螃蟹在中距离（3~7m）不是慢慢走过去，而是"滚"过去——更快、更有压迫感。

### 2.1 `CustomNavAgent` 加直线冲刺方法

**文件**：`Assets/Scripts/AI/Pathfinding/CustomNavAgent.cs`

在 `FaceTowards` 方法后面加：

```csharp
        /// <summary>
        /// 【指令】直线冲刺(无视寻路):立即朝指定方向以指定速度移动。
        /// 供滚动冲刺等"直线突进"场景使用;与 SetDestination(寻路)互斥。
        /// </summary>
        public void SetDirectVelocity(Vector3 direction, float speed)
        {
            if (_rb == null) return;

            Vector3 dir = direction;
            dir.y = 0f;
            if (dir.sqrMagnitude < 0.0001f) return;
            dir.Normalize();

            _rb.angularVelocity = Vector3.zero;
            _rb.rotation = Quaternion.LookRotation(dir, Vector3.up);
            _rb.velocity = new Vector3(dir.x * speed, _rb.velocity.y, dir.z * speed);
        }
```

### 2.5 新增 `RollChaseState.cs`

新建 `Assets/Scripts/AI/Enemy/State/RollChaseState.cs`：

```csharp
using UnityEngine;

namespace Emberwild.AI.Enemy.State
{
    /// <summary>
    /// 滚动冲刺状态:朝玩家直线高速突进,持续一段时间后回归 Chase/Idle。
    /// </summary>
    public class RollChaseState : IEnemyState
    {
        private float _rollEndTime;
        private Vector3 _rollDir;

        public void OnEnter(EnemyBrain brain)
        {
            // 先清掉寻路,让直线冲刺接管
            brain.Agent.Stop();
            brain.Animator.PlayRoll();
            brain.BB.LastRollTime = Time.time;
            _rollEndTime = Time.time + brain.RollDuration;

            var target = brain.BB.Target;
            if (target != null)
            {
                Vector3 dir = target.position - brain.transform.position;
                dir.y = 0f;
                _rollDir = dir.sqrMagnitude > 0.0001f ? dir.normalized : brain.transform.forward;
            }
            else
            {
                _rollDir = brain.transform.forward;
            }
        }

        public void OnUpdate(EnemyBrain brain)
        {
            if (Time.time >= _rollEndTime)
            {
                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
                return;
            }

            brain.Agent.SetDirectVelocity(_rollDir, brain.RollSpeed);
        }

        public void OnExit(EnemyBrain brain)
        {
            brain.Agent.Stop();
        }
    }
}
```

using UnityEngine;

namespace Emberwild.AI.Enemy.State
{
    /// <summary>缩壳防御状态:停止移动 → 缩壳减伤 → 超时出壳回归 Chase/Idle。</summary>
    public class HideState : IEnemyState

        {
            _hideEndTime = Time.time + brain.HideDuration;

            brain.Agent.Stop();

            brain.Animator.SetHidden(true);

                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
            }
        }

        public void OnExit(EnemyBrain brain)
        {
            brain.Animator.SetHidden(false);
            brain.Entity.Attribute.IsHidden = false;  // 关闭减伤
        }
    }
}
