## 步骤 2：新增实体契约 `ICombatEntity.cs`

**为什么？** `CharacterAttackHitEvent.Attacker` 现在写死是 `CharacterEntity`，但怪物是 `EnemyEntity`，塞不进去。我们定义一个**接口**，让玩家和怪物都"认领"它，`CombatDetector` 就只需认识接口、不再区分具体是谁。

新建 `Assets/Scripts/Combat/ICombatEntity.cs`：

```csharp
using UnityEngine;

namespace Emberwild.Combat
{
    /// <summary>
    /// 战斗实体统一契约。玩家(CharacterEntity)与怪物(EnemyEntity)都实现它，
    /// 使 CombatDetector 无需区分攻击者类型即可完成伤害判定。
    /// </summary>
    public interface ICombatEntity
    {
        /// <summary>武器/类型标识,用于查连招表(如 "Shell")。</summary>
        string SubType { get; }

        /// <summary>阵营。</summary>
        FactionType Faction { get; }

        /// <summary>世界坐标变换(用于判定框的位置与朝向)。</summary>
        Transform Transform { get; }

        /// <summary>攻击者的属性面板(AD/DEF/HP)。</summary>
        CombatAttribute Attribute { get; }
    }
}
```

**✅ 预期结果**：编译通过。

**❓ 常见问题**：
- "接口里为什么能放属性？" C# 接口可以声明属性，实现类负责提供 `get`，这正是我们想要的"统一访问入口"。

## 步骤 5：改造 `CombatDetector` 按阵营选目标层（🔴 核心）

**文件**：`Assets/Scripts/Combat/CombatDetector.cs`

**整体替换**为下面内容（关键变化：① 删掉写死的 `_targetLayerMask` 字段；② `OnAttackHitTriggered` 改用接口成员；③ 新增 `GetTargetLayer` 按阵营取层；④ `PerformPhysicsOverlap` 多一个 `targetLayerMask` 参数）：

```csharp
using Emberwild.Core.AppLog;
using Emberwild.Core.Events;
using Emberwild.Core.Singleton;
using Emberwild.Define;
using Emberwild.Manager;
using UnityEngine;

namespace Emberwild.Combat
{
    public class CombatDetector : Singleton<CombatDetector>
    {
        public CombatDetector()
        {
            EventBus.Subscribe<CharacterAttackHitEvent>(OnAttackHitTriggered);
            AppLog.Info("CombatDetector", "CombatDetector 就绪(按阵营判定目标层)");
        }

        public void Init()
        {
            AppLog.Info("CombatDetector", "CombatDetector Init");
        }

        private void OnAttackHitTriggered(CharacterAttackHitEvent evt)
        {
            var attacker = evt.Attacker;
            if (attacker == null) return;

            var attackerAttr = attacker.Attribute;
            if (attackerAttr == null || attackerAttr.IsDead) return;

            string subType = attacker.SubType;

            if (!DataManager.Instance.ComboGroupDict.TryGetValue(subType, out var comboDict) ||
                !comboDict.TryGetValue(evt.ComboIndex, out var atkDefine))
            {
                AppLog.Error("Combat", $"查表失败: 找不到 [{subType}] 的第 [{evt.ComboIndex}] 段攻击配置！");
                return;
            }

            Vector3 center = attacker.Transform.position + attacker.Transform.forward * atkDefine.OffsetZ;
            int targetMask = GetTargetLayer(attacker.Faction);
            Collider[] hits = PerformPhysicsOverlap(center, attacker.Transform, atkDefine, targetMask);
            ProcessHits(hits, attackerAttr, atkDefine, center, attacker.Transform.forward);
        }

        /// <summary>根据攻击者阵营,决定该打哪个物理层。</summary>
        private int GetTargetLayer(FactionType faction)
        {
            return faction == FactionType.Player
                ? LayerMask.GetMask("Monster")
                : LayerMask.GetMask("Player");
        }

        private Collider[] PerformPhysicsOverlap(Vector3 center, Transform attackerTransform, AttackDefine atkDefine, int targetLayerMask)
        {
            switch (atkDefine.HitboxType)
            {
                case 1: // 纯圆形判定
                    return Physics.OverlapSphere(center, atkDefine.Param1, targetLayerMask);
                case 2: // 矩形判定
                    Vector3 halfExtents = new Vector3(atkDefine.Param1 / 2f, 1f, atkDefine.Param2 / 2f);
                    Quaternion tiltedRotation = attackerTransform.rotation * Quaternion.Euler(0, 0, -20f);
                    return Physics.OverlapBox(center, halfExtents, tiltedRotation, targetLayerMask);
                case 3: // 扇形判定
                    return Physics.OverlapSphere(center, atkDefine.Param1, targetLayerMask);
                default:
                    AppLog.Error("Combat", $"未知的 HitboxType: {atkDefine.HitboxType}");
                    return new Collider[0];
            }
        }

        private void ProcessHits(Collider[] hits, CombatAttribute attackerAttr, AttackDefine atkDefine, Vector3 center, Vector3 forwardDir)
        {
            foreach (var hitCol in hits)
            {
                var defenderAttr = hitCol.GetComponent<CombatAttribute>();

                if (defenderAttr == null || defenderAttr.IsDead || defenderAttr == attackerAttr) continue;

                if (atkDefine.HitboxType == 3)
                {
                    Vector3 dirToTarget = (defenderAttr.transform.position - center).normalized;
                    float angle = Vector3.Angle(forwardDir, dirToTarget);
                    if (angle > atkDefine.Param2 / 2f)
                        continue;
                }

                float finalDamage = DamageCalculator.Calculate(attackerAttr, defenderAttr, atkDefine.DmgRate);
                defenderAttr.TakeDamage(finalDamage);
            }
        }
    }
}
```

**✅ 预期结果**：编译 0 报错。

**🧪 回归验证（必做，这一步绝不能跳过）**：运行游戏，用**玩家**攻击（按键与阶段一一致）打一只螃蟹，确认 Console 仍打印 `Shell 受到 X 伤害`。这一步证明"阵营改造没误伤玩家打怪"。

**❓ 常见问题**：
- 玩家攻击不再掉血 → 多半是 `GetTargetLayer` 逻辑写反，检查 `FactionType.Player → Monster` 这条分支。
- 报 "attacker.SubType / attacker.Attribute 不存在" → 说明实体类没正确实现接口，回步骤 4。

## 步骤 6：新增怪物攻击执行层 `EnemyCombat.cs`

**为什么？** 玩家有 `CharacterCombat`（听输入打人），怪物没有输入，需要一只由 AI 驱动的手。

新建 `Assets/Scripts/AI/Enemy/EnemyCombat.cs`：

```csharp
using Emberwild.Core.AppLog;
using Emberwild.Core.Events;
using UnityEngine;

namespace Emberwild.AI.Enemy
{
    /// <summary>
    /// 怪物攻击执行层 — AI 驱动版"手"。
    ///
    /// 职责:
    /// - 发起一次近战攻击:播 Bite Attack 动画 + 发布攻击事件。
    /// - 维护攻击硬直窗口(IsAttacking),保证"一刀一刀"不重叠。
    ///
    /// 严格不做:
    /// - 不判断"该不该打"(那是 AttackMeleeState 的事)。
    /// - 不算伤害(伤害由 CombatDetector + DamageCalculator 完成)。
    /// </summary>
    [DisallowMultipleComponent]
    public class EnemyCombat : MonoBehaviour
    {
        [Header("组件引用")]
        [SerializeField] private EnemyAnimator _animator;
        [SerializeField] private EnemyEntity _entity;

        [Header("攻击参数")]
        [Tooltip("单段近战攻击硬直时长(秒)")]
        [SerializeField] private float _attackDuration = 0.6f;

        private float _attackEndTime;

        /// <summary>是否正处于攻击硬直中。</summary>
        public bool IsAttacking => Time.time < _attackEndTime;

        /// <summary>阶段二只有单段攻击,固定 0。</summary>
        public int ComboIndex => 0;

        private void Awake()
        {
            if (_animator == null) _animator = GetComponent<EnemyAnimator>();
            if (_entity == null) _entity = GetComponent<EnemyEntity>();
        }

        /// <summary>AI 决策层调用:发起一次近战攻击。</summary>
        public void DoAttack()
        {
            if (IsAttacking) return;

            _attackEndTime = Time.time + _attackDuration;
            _animator?.PlayBiteAttack();
            EventBus.Publish(new CharacterAttackHitEvent(_entity, ComboIndex));
            AppLog.Info("Combat", $"{name} 发起近战攻击 combo={ComboIndex}");
        }
    }
}
```

**✅ 预期结果**：编译通过（此时还没人调用 `DoAttack`，属正常）。

### 7.2 新增 `AttackMeleeState.cs`

新建 `Assets/Scripts/AI/Enemy/State/AttackMeleeState.cs`：

```csharp
using UnityEngine;

namespace Emberwild.AI.Enemy.State
{
    /// <summary>
    /// 近战攻击状态:刹车 → 咬一口 → 硬直结束回归 Chase/Idle。
    /// </summary>
    public class AttackMeleeState : IEnemyState
    {
        public void OnEnter(EnemyBrain brain)
        {
            // 攻击必须站定
            brain.Agent.Stop();
            brain.Animator.SetMoveSpeed(0f);

            brain.Combat.DoAttack();
            brain.BB.LastAttackTime = Time.time;
        }

        public void OnUpdate(EnemyBrain brain)
        {
            // 硬直结束 → 看得到就继续追,看不到就待机
            if (!brain.Combat.IsAttacking)
            {
                brain.ChangeState(brain.BB.CanSeeTarget ? EnemyStateType.Chase : EnemyStateType.Idle);
            }
        }

        public void OnExit(EnemyBrain brain)
        {
            // 无需清理
        }
    }
}
```

### 7.3 `ChaseState` 加近战距离判定

```csharp
        public void OnUpdate(EnemyBrain brain)
        {
            var bb = brain.BB;

            if (bb.Target == null || !bb.CanSeeTarget)
            {
                brain.ChangeState(EnemyStateType.Idle);
                return;
            }

            // 距离足够近 → 切近战攻击
            if (bb.DistanceToTarget <= brain.MeleeRange)
            {
                brain.ChangeState(EnemyStateType.AttackMelee);
                return;
            }

            brain.Agent.SetDestination(bb.Target.position);
            brain.Animator.SetMoveSpeed(brain.NormalizedSpeed);
        }
```

> **为什么 `ComboGroup` 必须写 `Shell`？** 因为它要和 `CharacterDefine.txt` 里 Shell 的 `SubType`（`"Shell"`）**逐字一致**，`CombatDetector` 才会查表成功。拼错一个字母（历史 MC19 的 `SowrdAndShield` 就是这么栽的）就是"找不到配置"。

**✅ 预期结果**：改完后运行，怪物攻击时 Console **不再**出现 `查表失败: 找不到 [Shell] ...`。

**❓ 常见问题**：
- 报 JSON 解析错误 → 检查逗号：JSON 对象里最后一条后面不能有逗号，但**中间**条目之间必须有逗号。
- 若改动未生效 → `DataManager.Load()` 只在启动时读一次，改完数据表需**重新 Play**。

2. 控制玩家**走进螃蟹 1.6 米内**。

- [ ] Console 打印 `Shell → AttackMelee`
- [ ] 螃蟹停止移动，播放 `Bite Attack` 咬击动画
- [ ] Console 打印 `Shell 发起近战攻击 combo=0`
- [ ] 攻击命中 → Console 打印 `MC19 受到 X 伤害, 剩余 HP: Y`（玩家掉血）
